# 후원하기

이 사이트는 무료로 운영되며 광고가 없습니다. 다만 **한국어 번역·요약에 쓰는 AI API 비용**이 매달 발생합니다.

## 비용은 얼마나 드나

| 항목 | 비용 |
|---|---|
| 서버·호스팅 (GitHub Actions, GitHub Pages) | 0원 |
| 댓글 (GitHub Discussions) | 0원 |
| AI 요약 (Claude API) | 하루 30~80건 요약 기준 **월 약 1~3만 원** (수집량에 따라 변동) |

실제 사용량은 [수집 현황](../_generated/status.md) 페이지의 토큰 수로 공개됩니다.

## 후원 방법

- **GitHub Sponsors**: https://github.com/sponsors/hizorro88-rgb
- 그 밖의 후원 링크는 운영자가 준비되는 대로 여기에 추가합니다.

후원금은 API 비용에 우선 사용하고, 남으면 소스 확장(유료 뉴스 구독 등)에 씁니다. 사용 내역은 이 페이지에 공개합니다.

## 돈 말고 도울 수 있는 것

- 요약 오류 제보, 가이드 내용 검토 (특히 의료인 분들의 검수)
- 국내 임상시험·병원 정보 보완
- 이 사이트를 필요한 분께 알리기
