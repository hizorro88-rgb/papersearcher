# 수집 소스와 방법

!!! note "수집 범위의 한계"
    이 사이트의 "최신 연구·소식"은 아래 소스에서 췌장암 검색식으로 매일 자동 수집한 것만 담고 있어 **모든 연구를 포함하지 않습니다.** 수집 시작일(2026-10-06) 이전 논문, 학회 초록, 유료 뉴스, 검색식에 걸리지 않은 연구는 빠져 있습니다. 포괄적인 검색이 필요하면 PubMed와 ClinicalTrials.gov를 직접 이용하세요.

| 소스 | 무엇을 | 조회 조건 | 주기 |
|---|---|---|---|
| PubMed (NCBI E-utilities) | 논문 제목·초록·저널·출판 유형 | 췌장암 MeSH/제목·초록 검색식, 최근 3일 등록분 | 매일 |
| ClinicalTrials.gov API v2 | 임상시험 상태·단계·중재·선정기준·기관·연락처 | 췌장암 조건, 중재 연구, 최근 3일 갱신분 (첫 실행 시 모집 중 시험 전체) | 매일 |
| Europe PMC | 프리프린트(bioRxiv/medRxiv 등) | 제목에 췌장암 포함, 최근 3일 | 매일 |

검색식 원문은 저장소의 `config/sources.yaml`에 있습니다.

## 분류 규칙

- **카테고리**: `config/taxonomy.yaml`의 키워드 규칙으로 1차 분류 후 AI가 보정. 한 항목이 여러 카테고리에 들어갈 수 있습니다.
- **근거 수준**: PubMed 출판 유형과 제목 패턴으로 가이드라인 > 메타분석 > 3상 > 2상 > 1상 > 무작위 > 관찰 > 종설 > 증례 > 전임상 순으로 배지를 붙입니다.
- **중요도(0~1)**: 근거 수준 45% + 출처 신뢰도 25% + 췌장암 관련도 20% + 최신성 10%, 임상시험은 국내 기관·모집 중·상태 변경 시 가산. AI가 매긴 환자 관련도도 20% 반영. 0.6 이상이 "주요 소식"에 오릅니다.
- **관련도 하한**: 췌장암 핵심어가 제목·초록에 거의 없는 항목(0.25 미만)은 저장하지 않습니다.

## AI 요약

- 모델: Google Gemini(`gemini-3.8-flash`, 무료 등급) 또는 Anthropic Claude(`claude-opus-5-5`, 유료). 어떤 모델이 쓰였는지는 [수집 현황](../_generated/status.md)에 기록됩니다. 입력은 제목·초록·선정기준 원문뿐이며, 원문에 없는 내용을 쓰지 않도록 지시합니다.
- 출력은 JSON 스키마로 강제되어 카테고리·근거수준이 허용 목록 밖으로 나가지 않습니다.
- 실패하거나 API 키가 없으면 초록 앞부분 발췌로 대체되며 "초록 발췌"로 표시됩니다.

## 저작권·데이터 정책

- 저장하는 것: 제목, 초록(PubMed 공개 메타데이터), 등록 정보, 링크. 논문 전문은 저장하지 않습니다.
- 모든 항목은 원문 링크를 제공하며, 요약은 원문을 대체하지 않습니다.
- 수집 데이터는 저장소의 `data/` 아래 JSON으로 공개됩니다.

## 사람이 쓴 가이드의 출처

- **행복방 가이드**: 췌장암 환우·보호자 카카오 오픈채팅 「행복방」(췌장암 「행복하게 살자!」)의 운영자 버니님이 쓰고 초희님이 정리한 문서(2023년 10월 판)를 바탕으로 재구성했습니다. 출처는 각 페이지와 인용 단락에 "행복방"으로 표시합니다. 원문 중 출판물 요약, 개인 실명·직통번호, 상업 정보는 싣지 않았습니다.
- **응급 가이드**: 국립암센터, NCCN 환자용 가이드라인, ASCO, 대한췌장담도학회 등 공식 기관 자료. 각 페이지 하단에 출처를 적었습니다.
