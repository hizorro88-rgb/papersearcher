# 이 사이트에 대해

췌장암 환자·보호자·관심 있는 분들이 **최신 연구와 임상시험 정보를 한국어로, 한곳에서, 출처와 함께** 볼 수 있도록 만든 공개 위키입니다.

## 어떻게 만들어지나

1. 매일 아침 6시(한국 시간) GitHub Actions가 PubMed, ClinicalTrials.gov, Europe PMC를 조회합니다.
2. 새 논문·임상시험은 규칙과 AI로 분류하고, Claude 모델이 한국어 제목·요약·핵심 포인트·참여 조건을 만듭니다.
3. 결과는 GitHub 저장소에 JSON으로 저장되고(모든 변경 이력이 남음), 이 사이트가 자동으로 다시 만들어집니다.
4. 임상시험 상태 변경, 프리프린트의 정식 출판 등은 기존 항목에 "변경 이력"으로 반영됩니다.

자세한 소스·주기·규칙은 [수집 소스와 방법](sources.md), 현재 상태는 [수집 현황](../_generated/status.md)을 보세요.

## 누가 운영하나

개인이 운영하는 비영리 프로젝트입니다. 코드와 데이터는 모두 [GitHub](https://github.com/hizorro88-rgb/papersearcher)에 공개되어 있어 누구나 검증하고 기여할 수 있습니다.

## 한계

- 요약은 AI가 만든 것이라 오역·누락이 있을 수 있습니다. 중요한 내용은 반드시 원문을 확인하세요.
- 수집 소스에 없는 정보(학회 구두 발표, 유료 뉴스)는 빠질 수 있습니다.
- 응급 가이드는 공식 자료를 바탕으로 했지만 개인의 상황에 맞춘 조언이 아닙니다.
