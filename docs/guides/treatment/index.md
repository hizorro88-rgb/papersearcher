# 치료 알아보기

!!! info "이 섹션에 대해"
    이 섹션은 사람이 공식 자료를 바탕으로 쓴 설명입니다. 자동 수집되는 논문 소식과 달리 자주 바뀌지 않는 기본 지식을 다루며, 각 페이지 끝에 관련 최신 연구로 가는 링크를 두었습니다. 의료 조언이 아니며 치료 결정은 담당 의료진과 상의하세요.

## 진단 후 치료는 이렇게 나뉩니다

췌장암 치료는 **암이 어디까지 퍼졌는지(병기)** 와 **환자의 전신 상태**로 결정됩니다. 병기는 CT·MRI 등 영상에서 암이 주변 혈관을 어느 정도 감쌌는지로 나눕니다.

| 구분 | 뜻 | 보통의 치료 흐름 |
|---|---|---|
| **절제 가능** | 주요 혈관 침범 없이 수술로 떼어낼 수 있음 | 수술 → 수술 후 보조 항암 6개월. 최근엔 수술 전 항암(선행 항암)을 먼저 하는 경우도 늘고 있음 |
| **경계성 절제 가능** | 혈관을 일부 침범해 바로 수술하면 암이 남을 위험이 있음 | 선행 항암(± 방사선) → 반응이 좋으면 수술 |
| **국소 진행** | 혈관 침범이 심해 수술이 어렵지만 다른 장기 전이는 없음 | 항암 → 방사선 또는 수술 가능성 재평가 |
| **전이** | 간, 복막, 폐 등 다른 장기로 퍼짐 | 전신 항암이 중심. 증상 조절(시술·방사선·완화의료) 병행 |

약 20~30%만 진단 시 수술이 가능한 상태로 발견되고, 나머지는 항암이 치료의 중심이 됩니다.

- :material-hospital-box:{ .lg .middle } **[수술](surgery.md)**

- :material-needle:{ .lg .middle } **[시술](procedures.md)**

- :material-radioactive:{ .lg .middle } **[방사선치료](radiation.md)**

    언제 하는지, SBRT·세기조절·양성자·중입자, 준비와 부작용
