# 완화의료와 호스피스

**완화의료**는 "치료를 포기하는 것"이 아닙니다. 진단 초기부터 항암과 **함께** 통증·식사·수면·불안 같은 문제를 전문적으로 다스려 치료를 더 잘 받게 하는 의료입니다. 일찍 완화의료를 받은 환자가 삶의 질뿐 아니라 생존도 나았다는 연구가 여러 암에서 보고되었습니다. 췌장암은 증상 부담이 큰 암이라 특히 중요합니다.

## 완화의료에서 다루는 것

| 문제 | 접근 |
|---|---|
| **통증** | 단계적 진통제, 신경차단술, 방사선. → [통증 악화 응급 기준](../emergency/pain-crisis.md) · [시술 – 복강신경총 차단술](procedures.md#celiac) |
| **식사·체중** | 췌장효소제(PERT), 소량씩 자주, 영양 보충 음료, 식욕촉진제, 필요 시 영양 수액. 영양사 상담 |
| **황달·담관염** | 스텐트·배액관 → [시술](procedures.md) |
| **구역·장폐색** | 진토제, 십이지장 스텐트, 수액 |
| **복수·부종** | 복수천자, 이뇨제, 알부민 |
| **혈전** | 췌장암은 혈전 위험이 높아 예방·치료용 항응고제를 쓰기도 함 → [혈전 응급 기준](../emergency/thrombosis.md) |
| **당뇨** | 인슐린·혈당 관리 → [혈당 이상](../emergency/glucose.md) |
| **우울·불안·불면** | 암스트레스클리닉, 정신건강의학과, 상담. 보호자도 대상 |
| **피로·쇠약** | 가벼운 운동, 빈혈 교정, 수면 관리 |

병원마다 **완화의료팀(완화의료 자문)** 이 있어 담당의에게 의뢰를 요청할 수 있습니다.

## 호스피스는 언제, 어떻게

호스피스는 항암 등 적극적 치료가 더 이상 도움이 되지 않는 **말기** 단계에서 편안함과 존엄에 집중하는 돌봄입니다. 국내 제도(2017년 연명의료결정법)로 암 환자는 건강보험이 적용됩니다.

| 유형 | 내용 | 신청 |
|---|---|---|
| **입원형** | 호스피스 전문기관 병동에 입원. 통증·증상 조절, 가족 돌봄, 사별 지원 | 담당의의 말기 진단서 + 기관에 신청 |
| **가정형** | 의사·간호사·사회복지사가 **집으로 방문**. 익숙한 환경에서 지냄 | 가정형 호스피스 제공 기관에 문의 |
| **자문형** | 일반 병동·외래에 있으면서 호스피스팀의 상담·조정을 받음 | 입원 중인 병원의 완화의료팀 |

- 기관 찾기: **중앙호스피스센터** https://hospice.go.kr (지역별 검색), 국가암정보센터 1577-8899
- 호스피스를 시작해도 증상 조절을 위한 치료(배액, 방사선, 수혈 등)는 계속할 수 있습니다.
- "언제 이야기를 꺼내야 하나"가 가장 어렵습니다. 보통 **치료 선택지가 줄어들 때 미리** 알아 두면, 급해진 뒤에 결정하는 것보다 환자와 가족 모두에게 낫습니다.

## 연명의료 결정

- **사전연명의료의향서**: 19세 이상 누구나 건강할 때 등록기관(보건소, 일부 병원, 국민건강보험공단 지사)에서 작성. 심폐소생술, 인공호흡기, 혈액투석, 항암제 투여 등 연명의료에 대한 뜻을 미리 남김.
- **연명의료계획서**: 말기·임종 과정 환자가 담당의와 함께 작성.
- 등록·조회: 국립연명의료관리기관 https://www.lst.go.kr, 1855-0075
- 작성해 두면 가족이 대신 어려운 결정을 떠안지 않아도 됩니다. 언제든 철회·변경할 수 있습니다.

## 가족·보호자를 위해

- 보호자의 소진은 환자 돌봄의 질에 직결됩니다. 교대, 휴식, 상담을 미리 계획하세요.
- 경제적 지원: 산정특례(암 등록 시 본인부담 5%), 재난적 의료비 지원, 긴급복지, 장기요양보험(65세 이상 또는 노인성 질환)
- 돌봄 서비스: 서울시 병원 안심동행서비스(1533-1179), 각 병원 가정간호사업실
- 사별 후 지원: 호스피스 기관의 사별 가족 프로그램, 지역 정신건강복지센터.
