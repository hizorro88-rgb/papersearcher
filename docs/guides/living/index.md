# 투병 생활 가이드

치료 자체의 설명은 [치료 알아보기](../treatment/index.md)에, 바로 응급실에 가야 하는 기준은 [응급 가이드](../emergency/index.md)에 있습니다. 이 섹션은 그 사이, 즉 **집에서 치료를 이어 가는 동안 매일 부딪히는 문제**를 다룹니다.

!!! info "이 섹션에 대해"
    국립암센터, NCCN 환자용 가이드라인, ASCO·ONS(미국종양간호학회)의 부작용 관리 지침, 대한종양내과학회 자료를 바탕으로 작성했습니다. 환우 커뮤니티에서 자주 나오는 질문을 참고해 주제를 골랐습니다. 약 이름은 이해를 돕기 위한 예시이며 처방은 담당 의료진이 결정합니다.

<div class="grid cards" markdown>

- :material-calendar-check:{ .lg .middle } **[항암 시작 전 준비](before-chemo.md)** — 예방접종, 미리 받아둘 약, 동네 병원 확보, 기록 챙기기, 입원 가방
- :material-medical-bag:{ .lg .middle } **[항암 부작용별 대처](side-effects.md)** — 구토·오심, 설사·변비, 손발 저림, 구내염, 발열·호중구, 간수치, 피부, 주입 반응, 피로
- :material-food-apple:{ .lg .middle } **[식사와 영양](nutrition.md)** — 못 먹을 때 요령, 단백질, 췌장효소, 혈당, 식사 대용, 피해야 할 것
- :material-pill:{ .lg .middle } **[보조제와 건강식품](supplements.md)** — 항암과 충돌하는 것, 출혈 위험, 의료진에게 알리기
- :material-heart-pulse:{ .lg .middle } **[통증 조절의 원칙](pain.md)** — 통증에 대한 오해, 표현법, 진통제 단계와 부작용, 패치 주의, 비약물 요법
- :material-hospital-building:{ .lg .middle } **[병원 이용 요령](hospital-tips.md)** — 외래 3분 활용법, 기록·영상 복사, 지방 환자, 동행·가정간호·장기요양
