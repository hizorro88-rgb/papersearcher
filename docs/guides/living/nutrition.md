# 식사와 영양

췌장암은 **암 자체가 영양을 빼앗는 병**입니다. 소화효소가 줄어 먹어도 흡수가 안 되고, 통증·구역·포만감으로 섭취가 줄며, 암이 대사를 바꿔 근육이 빠집니다(악액질). 그래서 "무엇을 먹느냐"보다 **"얼마나 꾸준히 먹느냐"** 가 먼저이고, 체중과 근육을 지키는 것이 치료를 끝까지 받는 조건입니다.

## 원칙

- **소량씩 자주**: 하루 5~6회, 2~3시간마다. 한 끼를 다 못 먹어도 됩니다.
- **단백질 우선**: 끼니마다 손바닥 크기의 단백질(계란, 생선, 두부, 살코기, 콩, 유제품). 체중 1kg당 하루 1.2~1.5g이 목표.
- **열량도 필요**: 체중이 줄고 있으면 지방을 제한하지 않습니다. 췌장효소제를 함께 먹으면 지방도 흡수됩니다.
- **부드럽고 담백하게**: 튀김·매운 것·너무 기름진 것은 소화가 힘들 수 있지만, 먹히는 것이 우선입니다.
- **수분**: 하루 1.5~2L. 설사·구토가 있으면 전해질 음료.
- **술은 피하고** 카페인은 줄입니다.

## 단백질, 어디에 얼마나 들어 있나

하루 목표(체중 60kg 기준 약 70~90g)를 채우려면 끼니마다 20g 안팎이 필요합니다. 대략적인 함량입니다.

| 음식 (조리 후) | 1회 분량 | 단백질 |
|---|---|---|
| 닭가슴살 | 100g | 23g |
| 소고기 안심 | 100g | 20g |
| 돼지고기 안심 | 100g | 22g |
| 고등어·연어·갈치 | 100g | 20g |
| 새우·오징어·문어 | 100g | 18~20g |
| 계란 | 1개(50g) | 6g |
| 두부 | 1/3모(100g) | 8g |
| 검은콩·병아리콩(삶은 것) | 100g | 9~10g |
| 우유·두유 | 200ml | 6g |
| 그릭요거트 | 100g | 9g |
| 치즈 | 1장(20g) | 4g |
| 경구 영양 보충 음료 | 200ml 1팩 | 7~12g |

(국가표준식품성분표 기준 근사치. 제품은 라벨을 확인하세요.)

## 못 먹을 때 요령

| 상황 | 요령 |
|---|---|
| 울렁거림 | 차갑거나 실온인 음식(냄새가 덜 남), 누룽지, 메밀국수, 과일, 물김치, 생강차·탄산수. 조리는 다른 사람이 |
| 입맛이 없음 | 하루 중 가장 입맛 좋은 때(보통 아침)에 가장 많이. 식전 가벼운 산책 |
| 금방 배부름 | 식사와 음료를 분리(물은 식간에). 열량 높은 소량 음식(견과류, 치즈, 아보카도, 영양 음료) |
| 쇠맛·모래맛 | 플라스틱 수저, 레몬·식초 양념, 민트 사탕. 고기 맛이 싫으면 계란·두부·생선으로 단백질 |
| 구내염 | 부드럽고 미지근하게, 빨대 사용, 식전 처방 가글 |
| 설사 | 바나나·쌀·사과·토스트처럼 자극 없는 음식, 수분·전해질. 기름진 변이면 효소제 점검 |

## 췌장효소제(PERT) — 췌장암 환자의 필수 약 { #enzyme }

췌장 기능이 떨어지거나 수술로 췌장을 떼면 지방·단백질을 소화하는 효소가 부족해집니다. 증상: 기름지고 물에 뜨는 변, 잦은 방귀·복부 팽만, 식후 더부룩함, 체중 감소.

- **식사 시작과 함께** 복용하고, 식사가 길면 중간에 나눠 먹습니다. 간식에도 절반 용량.
- 효과가 없으면 용량을 올리거나 위산 억제제를 추가합니다. 증상이 남는데도 참는 분이 많습니다. 의료진에게 말하세요.
- 수술 후, 특히 췌두십이지장절제술 후에는 대부분 필요합니다. → [수술 후 생활](../treatment/surgery.md)

## 혈당

- 췌장암은 당뇨를 새로 일으키거나 악화시킵니다. 스테로이드 전처치, 식욕촉진제, 수술도 혈당을 흔듭니다.
- 집에서 혈당을 재고 기록합니다. 저혈당(70 미만)은 즉시 당분 섭취, 의식이 흐리면 119. → [혈당 이상](../emergency/glucose.md)
- 혈당 때문에 식사를 지나치게 제한하면 체중이 빠집니다. 당뇨 식단보다 **영양 유지가 우선**이며 약으로 혈당을 조절합니다.

## 식사 대용과 보충

| 종류 | 예 | 1회 분량 열량/단백질 | 쓰임 |
|---|---|---|---|
| 경구 영양 보충 음료(시판) | 뉴케어, 그린비아, 메디웰 등 | 200ml 200~400kcal / 7~16g | 식사 사이 보충. 맛이 여러 가지라 입에 맞는 것을 찾음 |
| 환자용 균형영양식(처방) | 엔커버, 하모닐란 등 | 1팩 250~300kcal / 10~12g | 의료진 처방, 급여 적용 가능 |
| 영양죽·분말 | 시니어 영양죽류 | 1포 150~170kcal / 6g | 따뜻한 식사를 원할 때 |
| 유아식 파우치 | 시판 이유식 | 1팩 55~65kcal / 2~3g | 수술 직후·구내염 때 부드럽게 넘기기 좋지만 열량이 낮아 보충용 |
| 단백질 파우더·스무디 | 유청·대두 단백 | 1스쿱 20g 안팎 | 죽·우유·수프에 섞어 단백질 보강 |

- 삼키기 힘들면 묽은 죽, 수프, 스무디부터. 유아식은 부드럽지만 열량이 낮으니 영양 음료와 함께.
- 입으로 충분히 못 먹는 기간이 길어지면 영양 수액이나 영양관을 의료진과 상의합니다. 집 근처 병원에서 수액을 맞을 수 있게 미리 연계해 두면 편합니다.

## 호중구가 낮을 때 피할 것

항암 후 7~14일(백혈구 저점)에는 **날것과 덜 익힌 것**을 피합니다: 회·초밥·육회·생굴, 반숙 계란, 비살균 우유·치즈, 씻지 않은 생채소·과일(껍질 벗겨 먹기), 뷔페·오래 둔 음식. 백혈구 촉진제로 수치가 올라도 같은 주의를 유지합니다.

## 흔한 질문

- **우유·고기·설탕을 끊어야 하나요?** 근거가 없습니다. 특정 음식이 암을 키운다는 주장보다 체중·근육 유지가 생존과 더 직접 연관됩니다.
- **현미·채식이 좋은가요?** 소화가 힘든 시기에는 흰쌀·부드러운 음식이 낫습니다. 상태가 좋을 때 통곡물·채소를 늘리면 됩니다.
- **고기 국물·사골이 혈구를 올리나요?** 단백질과 열량 공급원으로 좋지만 혈구를 직접 올리는 음식은 없습니다. 골고루 먹는 것이 답입니다.
- **차는 뭘 마시나요?** 물 대신 마시기에는 보리차·현미차·옥수수차처럼 카페인·탄닌이 없는 것이 무난합니다. 녹차·홍차는 카페인과 철분 흡수 저해가 있어 양을 조절합니다.
