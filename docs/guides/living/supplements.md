# 보조제와 건강식품

암 진단 후 가장 많이 듣는 말이 "이거 먹으면 좋대"입니다. 원칙은 단순합니다. **근거가 있는 것은 적게, 근거가 없는 것은 비싸고 위험할 수 있다.** 그리고 무엇을 먹든 **담당 의료진에게 알립니다.** 숨기면 간수치 상승이나 출혈의 원인을 찾지 못합니다.

## 근거가 비교적 분명한 것

| 항목 | 근거 | 비고 |
|---|---|---|
| **췌장효소제(PERT)** | 췌장 외분비 부족 시 표준 치료 | 처방약. → [식사와 영양](nutrition.md#enzyme) |
| **비타민D** | 결핍이 흔하고 교정은 뼈 건강에 도움. 암 생존 개선 근거는 약함 | 혈액검사로 수치 확인 후 보충 |
| **비타민B12, 철분, 엽산** | 수술·흡수 장애로 결핍 시 | 검사로 확인 후 |
| **경구 영양 보충 음료** | 체중 유지에 효과 | → [식사와 영양](nutrition.md) |
| **오메가-3(EPA)** | 악액질에서 체중·식욕 개선 보고가 일부 있음 | 출혈 경향·수술 전 주의 |

## 주의가 필요한 것

| 분류 | 예 | 이유 |
|---|---|---|
| **고용량 항산화제** | 비타민C 고용량(주사 포함), 비타민E, 베타카로틴, 셀레늄, 코엔자임Q10, 글루타치온, 녹차 추출물 | 항암제·방사선은 산화 스트레스로 암세포를 죽이는데, 고용량 항산화제가 이를 방해할 수 있다는 우려. 치료 중에는 피하는 것이 보수적 권고 |
| **출혈 위험을 높이는 것** | 커큐민(강황), 오메가-3 고용량, 은행잎, 마늘·생강 농축물, 변형감귤펙틴, 비타민E | 혈소판 감소·항응고제 복용·시술·수술 전에는 중단 |
| **간독성 보고가 있는 것** | 개똥쑥(아르테미시닌), 일부 한약재, 녹차 추출물 고용량, 카바 | 간수치 상승 시 가장 먼저 의심 |
| **항암제 대사에 영향** | 세인트존스워트, 자몽, 일부 한약 | 약 혈중 농도를 바꿈 |
| **호르몬 작용** | 멜라토닌 고용량, 대두 이소플라본 농축물 | 근거 불충분, 상호작용 가능 |
| "암세포만 죽인다"는 천연물 | 포포(아세토제닌), 그라비올라, 비타민B17(아미그달린) | 사람 대상 근거 없음. 신경독성·시안화물 독성 보고 |
| 면역 보조 표방 | 베타글루칸, 버섯 추출물(AHCC 등), 스피루리나 | 삶의 질 개선 보고는 일부 있으나 생존 근거 없음. 스피루리나는 간독성·중금속 오염 보고. 염증 상태에서의 영향 불명 |
| 전신 효소제 | 브로멜라인·파파인·트립신 복합제 | 소화효소제와 다름. 항암 보조 근거 약함, 공복 장기 복용 시 위장 자극 |

## 흔히 듣는 주장에 대해

- **"면역력을 올려 준다"**: 면역은 수치 하나로 올리고 내리는 것이 아닙니다. 잘 먹고, 자고, 움직이고, 감염을 피하는 것이 면역 관리입니다.
- **"다제내성 암세포를 없앤다", "전이를 막는다"**: 세포 실험 결과를 사람에게 그대로 적용한 광고 문구입니다. 사람 대상 임상 근거가 있는지 물어보세요.
- **"병원에서는 안 알려 준다"**: 근거가 있으면 가이드라인에 들어갑니다. 들어가지 않은 데는 이유가 있습니다.
- 고가 제품일수록, 개인 간증 중심일수록, "항암을 끊고 이것만" 식일수록 경계합니다.

## 의료진에게 알리는 법

- 복용 중인 보조제·한약·건강식품을 **제품명·성분·용량·시작일**로 적어 외래 때 보여 줍니다.
- 수술·시술·조직검사 **1~2주 전**에는 출혈 위험이 있는 것을 중단할지 확인합니다.
- 간수치·혈소판이 떨어지면 보조제부터 끊어 보는 것이 진단의 첫 단계입니다.
- 종양내과 의사가 보조제에 회의적인 것은 성분을 몰라서가 아니라 근거가 없어서인 경우가 대부분입니다. 그래도 물어보는 것이 숨기는 것보다 낫습니다.
