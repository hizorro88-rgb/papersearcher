## 췌장과 주변 구조

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 췌장 | pancreas | 위 뒤에 가로로 누운 15cm 정도의 장기. 소화효소(외분비)와 인슐린·글루카곤(내분비)을 만든다 |
| 췌두부 / 췌체부 / 췌미부 | head / body / tail | 췌장의 머리(십이지장 쪽) / 몸통 / 꼬리(비장 쪽). 머리 암은 황달로 비교적 일찍 발견되고, 몸통·꼬리 암은 늦게 발견되는 경우가 많다 |
| 췌관 | pancreatic duct | 췌장액이 흐르는 관. 췌장암의 90% 이상이 이 관의 세포에서 생긴다 |
| 담관(담도) | bile duct | 간에서 만든 담즙이 십이지장으로 내려가는 관. 췌장 머리를 지나므로 머리 암이 누르면 황달이 생긴다 |
| 담낭 | gallbladder | 담즙을 저장하는 주머니. 휘플 수술 때 함께 제거 |
| 십이지장 | duodenum | 위 다음의 소장 첫 부분. 췌장 머리와 붙어 있어 휘플 수술 때 함께 제거 |
| 팽대부(바터 팽대부) | ampulla of Vater | 담관과 췌관이 만나 십이지장으로 열리는 곳 |
| 비장 | spleen | 췌장 꼬리 옆 장기. 원위췌장절제 때 함께 제거하는 경우가 많고, 제거 후 예방접종이 필요 |
| 상장간막동맥 / 정맥 | SMA / SMV | 췌장 뒤를 지나는 큰 혈관. 암이 얼마나 감쌌는지가 수술 가능 여부를 가른다 |
| 복강동맥 | celiac artery | 위·간·비장으로 가는 큰 동맥. 침범 시 수술이 어렵다 |
| 문맥 | portal vein | 장에서 간으로 가는 정맥. 침범 시 절제·재건을 함께 하기도 |
| 복강신경총 | celiac plexus | 췌장 뒤의 신경 다발. 췌장암 등 통증의 통로. 신경차단술의 대상 |
| 후복막 | retroperitoneum | 배 안의 가장 뒤쪽 공간. 췌장이 여기 있어 수술 접근이 어렵다 |
| 복막 | peritoneum | 배 안을 둘러싼 얇은 막. 암이 퍼지면 복막파종·복수가 생긴다 |

## 질병·상태

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 췌관선암 | PDAC (pancreatic ductal adenocarcinoma) | 췌장암의 90% 이상. 보통 "췌장암"은 이것을 뜻한다 |
| 선암 | adenocarcinoma | 분비샘 세포에서 생긴 암 |
| 췌장 신경내분비종양 | pNET | 호르몬 세포에서 생긴 다른 종류의 췌장 종양. 경과와 치료가 췌관선암과 전혀 다르다 |
| 췌관내 유두상 점액종양 | IPMN | 췌관에 생기는 낭종성 종양. 일부는 암으로 진행하므로 추적·수술 대상 |
| 낭종 | cyst | 물혹. 대부분 양성이지만 종류에 따라 추적이 필요 |
| 만성 췌장염 | chronic pancreatitis | 췌장의 만성 염증. 췌장암 위험인자이며 암과 구별이 어려울 때가 있다 |
| 황달 | jaundice | 담즙이 막혀 피부·눈이 노래지고 소변이 진해짐. 가려움, 회색 변 동반 |
| 담관염 | cholangitis | 막힌 담관에 세균 감염. 황달+발열+복통이면 응급 |
| 복수 | ascites | 배에 물이 참. 복막 전이, 저알부민 등이 원인 |
| 전이 | metastasis | 암이 처음 생긴 곳에서 다른 장기(간, 폐, 복막, 뼈)로 퍼짐 |
| 원격전이 | distant metastasis | 멀리 떨어진 장기로의 전이. 4기의 기준 |
| 복막파종 | peritoneal seeding | 암세포가 복막에 흩뿌려지듯 퍼진 상태 |
| 국소 재발 | local recurrence | 수술한 자리 근처에서 다시 자람 |
| 악액질 | cachexia | 암 때문에 근육과 체중이 빠지는 대사 상태. 먹어도 회복이 어렵다 |
| 근감소증 | sarcopenia | 근육량·근력 감소. 수술·항암 결과와 연관 |
| 외분비 기능 부전 | PEI / EPI | 소화효소 부족. 지방변, 체중 감소. 췌장효소제로 치료 |
| 췌장성 당뇨 | type 3c diabetes | 췌장 질환·절제로 생긴 당뇨 |
| 혈전 / 심부정맥혈전증 / 폐색전증 | VTE / DVT / PE | 혈관 안에서 피가 굳음. 췌장암은 위험이 높다. 폐로 가면 응급 |
| 섬망 | delirium | 갑작스러운 의식·주의력 장애. 감염·약물·탈수의 경고 신호 |

## 검사·진단

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 전산화단층촬영 | CT | X선으로 몸의 단면을 찍는 검사. 췌장 전용 프로토콜(얇게, 여러 시기)로 병기를 정한다 |
| 조영제 | contrast | CT·MRI에서 혈관·장기를 잘 보이게 하는 약. 신장 기능·알레르기 확인 필요 |
| 자기공명영상 | MRI | 자기장으로 찍는 검사. 간 전이, 담관·췌관 확인에 유리 |
| 자기공명 담췌관조영술 | MRCP | MRI로 담관·췌관 모양을 보는 검사 |
| 내시경초음파 | EUS | 위·십이지장 안에서 초음파로 췌장을 가까이 보고 조직을 뗌 |
| 세침흡인 / 세침생검 | FNA / FNB | 가는 바늘로 세포·조직을 뽑는 조직검사. 보통 EUS로 시행 |
| 내시경 역행 담췌관조영술 | ERCP | 내시경으로 담관·췌관에 조영제를 넣고 스텐트를 삽입하는 시술. 황달 치료 |
| 양전자방출단층촬영 | PET-CT | 포도당 유사 물질로 전신 전이를 찾는 검사 |
| 복강경 탐색 | staging laparoscopy | 수술 전 배 안을 카메라로 보고 작은 전이를 확인 |
| 조직검사 / 병리 | biopsy / pathology | 떼어낸 조직을 현미경으로 보는 검사. 암 종류와 등급을 확정 |
| 종양표지자 | tumor marker | 암이 있을 때 혈액에서 올라가는 물질. CA19-9, CEA |
| CA19-9 | | 췌장암에서 가장 많이 보는 종양표지자. 치료 반응·재발 추적용. 황달만으로도 오르고, 5~10%는 원래 만들지 않는다 |
| CEA | | 암태아성항원. 보조 종양표지자 |
| 차세대 염기서열 분석 | NGS | 종양 조직의 여러 유전자 변이를 한 번에 분석. 표적치료·임상시험 조건 확인 |
| 생식세포 유전자 검사 | germline test | 혈액으로 타고난 변이(BRCA 등)를 검사. 치료 선택과 가족 검진에 영향 |
| 순환 종양 DNA | ctDNA | 혈액 속 암세포 DNA. 액체생검 |
| 판독지 | radiology report | 영상의학과 의사가 CT·MRI를 읽고 쓴 소견서. 발급받아 읽어 둘 것 |

## 병기와 수술 가능성

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 병기 | stage | 암이 퍼진 정도. 1~4기 |
| TNM | | T(종양 크기), N(림프절 전이), M(원격전이)으로 병기를 정하는 체계 |
| 절제 가능 | resectable | 수술로 떼어낼 수 있는 상태 |
| 경계성 절제 가능 | borderline resectable | 혈관을 일부 침범해 바로 수술하면 암이 남을 위험. 보통 선행 항암 후 수술 |
| 국소 진행 | locally advanced | 혈관 침범이 심해 수술이 어렵지만 원격전이는 없음 |
| 전이성 | metastatic | 다른 장기로 퍼진 4기 |
| 절제연 R0 / R1 / R2 | resection margin | 떼어낸 조직 가장자리에 암이 없음 / 현미경으로 남음 / 눈으로 보이게 남음 |
| 림프절 전이 | nodal metastasis | 주변 림프절에 암이 퍼짐. N1(1~3개), N2(4개 이상) |
| 전환 수술 | conversion surgery | 처음엔 수술 불가였다가 항암 반응 후 수술하게 된 경우 |
| 수행 능력 | ECOG PS | 환자의 일상 활동 정도. 0 정상, 1 가벼운 일 가능, 2 낮의 절반 이상 활동, 3 절반 이상 누움, 4 완전 와상. 치료 선택 기준 |

## 치료 일반

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 1차 / 2차 치료 | first-line / second-line | 처음 받는 항암 / 진행 후 다음 항암 |
| 선행(수술 전) 항암 | neoadjuvant | 수술 전에 암을 줄이고 미세 전이를 치료하려는 항암 |
| 보조(수술 후) 항암 | adjuvant | 수술 후 재발을 줄이려는 항암. 보통 6개월 |
| 유지요법 | maintenance | 반응이 좋을 때 약한 약으로 유지 |
| 근치적 / 고식적(완화적) | curative / palliative | 완치 목표 / 증상 완화·생존 연장 목표 |
| 다학제 진료 | multidisciplinary team (MDT) | 외과·종양내과·영상·방사선·소화기내과가 함께 치료 방침 결정 |
| 2차 의견 | second opinion | 다른 병원·의사의 의견. 환자의 권리 |
| 표준치료 | standard of care | 근거로 확립된 치료. 가이드라인(NCCN, ESMO, 국내)에 수록 |
| 허가 외 사용 | off-label | 허가된 적응증 밖으로 쓰는 것. 근거와 비용 확인 필요 |
| 급여 / 비급여 | | 건강보험 적용 / 전액 본인부담 |
| 산정특례 | | 암 등록 시 5년간 본인부담 5% |
| 휴약 | drug holiday | 부작용·반응에 따라 항암을 쉬는 기간 |
| 내성 | resistance | 약이 더 이상 듣지 않게 됨 |

## 수술

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 췌두십이지장절제술(휘플 수술) | PD / Whipple | 췌장 머리, 십이지장, 담낭, 담관 아래쪽(+위 일부)을 떼고 다시 잇는 수술 |
| 유문보존 췌두십이지장절제술 | PPPD | 위를 보존하는 휘플 수술 |
| 원위췌장절제술 | DP | 췌장 몸통·꼬리 절제. 보통 비장 포함 |
| 근치적 선행 모듈식 췌비장절제술 | RAMPS | 몸통·꼬리 암에서 더 넓게 떼는 방식 |
| 췌장 전절제술 | TP | 췌장 전체 제거. 평생 인슐린·효소제 |
| 복강경 / 로봇 수술 | laparoscopic / robotic | 작은 구멍으로 하는 최소침습 수술 |
| 혈관 절제·재건 | vascular resection | 침범된 정맥·동맥을 떼고 다시 연결 |
| 문합 | anastomosis | 장기를 잘라낸 뒤 다시 이은 부위 |
| 췌장루(췌액 누출) | POPF | 문합 부위에서 췌액이 샘. 췌장 수술의 대표 합병증 |
| 위배출 지연 | DGE | 수술 후 음식이 위에서 안 내려가는 상태 |
| 장유착 / 장폐색 | adhesion / ileus | 수술 후 장이 들러붙음 / 장이 막힘 |
| 배액관 | drain | 수술 부위의 체액을 빼는 관 |
| 수술 후 조기 회복 프로그램 | ERAS | 금식 최소화, 조기 보행 등으로 회복을 앞당기는 관리 |
| 우회술 | bypass | 막힌 담도·장을 떼지 않고 통로만 만드는 수술 |

## 시술

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 담도 스텐트 | biliary stent | 막힌 담관에 넣는 관. 플라스틱(단기)·금속(장기) |
| 경피 경간 담도 배액술 | PTBD | 옆구리 피부를 통해 간 속 담관에 관을 꽂아 담즙을 밖으로 빼는 시술 |
| 내시경초음파 유도 담도배액술 | EUS-BD | ERCP가 안 될 때 위에서 담관으로 길을 내는 시술 |
| 십이지장(위출구) 스텐트 | duodenal stent | 막힌 십이지장에 넣는 금속관 |
| 케모포트 | chemoport | 쇄골 아래 피부 밑에 심는 항암 주사용 장치 |
| 말초삽입 중심정맥관 | PICC | 팔 정맥을 통해 넣는 긴 주사관. 케모포트 대안 |
| 복수천자 | paracentesis | 배에 찬 물을 바늘로 빼는 시술 |
| 복강신경총 차단술 | celiac plexus neurolysis (CPN) | 통증 신경에 알코올 등을 주입해 통증을 줄이는 시술 |
| 경피 내시경 위루술 | PEG | 내시경으로 위에 영양관을 만드는 시술 |
| 비가역적 전기천공법(나노나이프) | IRE | 전기 펄스로 종양을 파괴하는 국소 치료. 표준은 아님 |
| 고주파 열치료 | RFA | 열로 종양을 태우는 국소 치료 |
| 색전술 | embolization | 출혈 혈관을 막는 시술 |
| 피듀셜 | fiducial | 방사선 조준용으로 종양 근처에 심는 작은 금속 표지 |

## 항암제·요법

| 용어 | 영어·약어 | 뜻 |
|---|---|---|
| 항암화학요법 | chemotherapy | 세포독성 약물로 암세포를 죽이는 치료 |
| 세포독성 항암제 | cytotoxic | 빠르게 분열하는 세포를 공격하는 전통적 항암제. 폴피리녹스·젬아 |
| 표적치료제 | targeted therapy | 특정 유전자 변이·단백질만 겨냥하는 약 |
| 면역항암제(면역관문억제제) | immunotherapy / ICI | 면역세포가 암을 공격하게 하는 약. 췌장암은 MSI-H 등 일부에서만 효과 |
| 항체-약물 접합체 | ADC | 항체에 항암제를 붙여 암세포에 전달하는 약 |
