# 혈전(정맥혈전색전증), 폐색전증

췌장암은 모든 암 중 혈전 위험이 가장 높은 축에 듭니다. 다리 정맥에 생긴 혈전이 폐로 가면(폐색전증) 생명을 위협합니다.

## 즉시 119·응급실

- 갑작스런 **호흡곤란**, 숨 쉴 때 가슴 통증, 피 섞인 가래
- 심장이 빨리 뛰고 어지럽거나 실신
- 한쪽 다리가 붓고 아프면서 위 증상이 동반

## 당일 병원 연락

- 한쪽 종아리·허벅지가 붓고 뻐근하며 만지면 아픔, 피부가 붉거나 따뜻함
- 팔(케모포트 쪽)이 붓고 아픔 (카테터 관련 혈전)

## 항응고제를 쓰는 분

- 출혈 증상(흑색변, 토혈, 멈추지 않는 코피)이 생기면 → [출혈](bleeding.md)
- 임의로 중단하지 말고, 시술·검사 전에는 반드시 중단 여부를 의료진에게 확인

## 의료진에게 전달할 정보

- 증상 시작 시각, 다리 둘레 차이
- 항응고제 사용 여부, 최근 수술·장기 침상 안정 여부
