# 토혈, 흑색변, 혈변

종양이 십이지장이나 위를 침범하거나, 항응고제를 쓰거나, 혈소판이 낮을 때 출혈이 생길 수 있습니다.

## 즉시 119·응급실

- 피를 토하거나 커피 찌꺼기 같은 것을 토함
- 검은 타르 같은 변(흑색변)이나 선홍색 혈변이 **여러 번**
- 어지러움, 식은땀, 심장이 빨리 뜀, 실신 (출혈량이 많다는 신호)
- 항응고제(에녹사파린, 아픽사반, 리바록사반 등)를 쓰는 중의 출혈

## 당일 병원 연락

- 소량의 코피·잇몸 출혈이 멈추지 않음 (혈소판 감소 가능)
- 피부에 멍·점상 출혈이 갑자기 많이 생김
- 배액관·스텐트 주변의 출혈

## 하지 말아야 할 것

- 의료진 확인 없이 항응고제·아스피린을 임의로 끊거나 계속 먹기 (둘 다 위험할 수 있어 반드시 전화로 확인)
- 출혈 중 음식·물 섭취 (내시경이 필요할 수 있음)

## 의료진에게 전달할 정보

- 항응고제·항혈소판제 이름과 마지막 복용 시각
- 최근 혈소판 수치, 마지막 항암일
- 토한 양·변의 색과 횟수
