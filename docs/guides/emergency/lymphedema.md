# 부종·림프부종

## 먼저 응급을 배제

| 붓기의 모양 | 의심 | 대처 |
|---|---|---|
| **한쪽** 다리가 갑자기 붓고 아프고 따뜻함 | 심부정맥혈전증 | 당일 병원. 숨참·가슴 통증 동반 시 119 → [혈전·호흡곤란](thrombosis.md) |
| 양쪽 다리·발, 눌러서 자국 | 저알부민(영양 부족), 심부전, 신장, 약물(스테로이드·메게스트롤) | 외래에서 원인 검사 |
| 배가 부풀고 다리도 부음 | 복수 | → [시술 – 복수천자](../treatment/procedures.md#paracentesis) |
| 수술·림프절 절제 쪽 팔다리가 서서히 붓고 무겁고 단단해짐 | 림프부종 | 아래 관리. 초기 치료가 중요 |

## 림프부종 관리

- **초기에 시작**: 눌러서 자국이 남는 단계에서 관리하면 되돌릴 수 있지만, 단단해지면(섬유화) 어렵습니다.
- **거상**: 쉴 때 부은 부위를 심장보다 높게. 손발을 쥐었다 펴는 펌프 운동.
- **압박**: 처방받은 압박스타킹·슬리브를 낮에 착용. 밤에는 벗습니다.
- **운동**: 가벼운 걷기, 스트레칭, 수영. 근육 펌프가 림프 흐름을 돕습니다.
- **피부 관리**: 보습, 상처·벌레 물림 즉시 소독. 붓는 쪽 팔에서 채혈·혈압 측정·주사를 피합니다.
- **전문 치료**: 재활의학과의 림프 도수 마사지(MLD)와 압박 붕대. 암이 활발히 진행 중인 부위에는 마사지를 하지 않으므로 의료진 판단이 필요합니다.
- **피할 것**: 뜨거운 찜질·사우나·온천, 꽉 조이는 옷·시계, 무거운 물건 들기, 장시간 비행 시 압박 없이 앉아 있기, 부항·침·뜸.

## 바로 연락

- 부은 부위가 붉고 뜨겁고 열이 남 → 봉와직염(세균 감염). 항생제가 필요합니다.
- 양쪽 둘레 차이가 2cm 이상 벌어짐, 통증 증가.
