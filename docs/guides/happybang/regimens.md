# 항암제 종류와 순서

!!! quote "출처: 행복방"
    행복방 문서의 "췌장암 항암제 종류"와 "췌담도내과에서 주로 쓰는 항암제 부작용 정리"를 옮겼습니다. 2023년 기준이며 최신 신약·임상시험은 이 사이트의 [신약·치료제](../../_generated/categories/drug.md)와 [임상시험](../../_generated/trials/index.md)에서 매일 갱신됩니다.

## 췌장암 항암 요법 (행복방 정리)

| 이름 | 구성 | 비고 |
|---|---|---|
| **젬아** | 젬시타빈 + 아브락산(나노 알부민에 파클리탁셀을 감싼 약) | 고령·전이·체력 약한 경우 1차로 선택되기도 |
| 젬시아 | 젬시타빈 + 시스플라틴 + 아브락산 | 부작용이 심해 잘 쓰지 않음. BRCA 변이에 고려 |
| **폴피리녹스** | 이리노테칸 + 류코보린 + 5-FU + 옥살리플라틴 | 부작용으로 힘들면 폴피리나 폴폭스로 변경 |
| 폴피리 | 이리노테칸 + 류코보린 + 5-FU | |
| 폴폭스 | 류코보린 + 5-FU + 옥살리플라틴 | |
| **나폴리(오니바이드)** | 오니바이드(이리노테칸 리포좀) + 류코보린 + 5-FU | 폴피리와 비슷. 오니바이드와 여러 약제 병용 임상 진행 중(오니+시스+5FU, 오니+옥살리+TS-1 등) |
| 젤로다(카페시타빈) | 경구용 5-FU | 먹는 항암제. 피부 부작용이 생각보다 심함 |
| 젤록스 | 젤로다 + 옥살리플라틴 | 젬시타빈 기반 내성 시 또는 전이성 2차 치료로 고려 |
| TS-1 | 경구용 5-FU | 편리하고 부작용이 적어 체력이 좋지 않거나 고령인 환자에게 고려 |

### 표적·면역 항암제

| 약 | 대상 | 비고 |
|---|---|---|
| 린파자(올라파립) | BRCA, ATM 변이 | BRCA 변이는 백금계 항암(시스플라틴, 옥살리플라틴)도 효과적 |
| 타세바(엘로티닙) | EGFR 변이, 젬시타빈과 병용 | 젬아·폴피리녹스가 있어 잘 쓰이지 않음 |
| 메키니스트(트라메티닙)+HCQ | BRAF, KRAS 변이 | 3차 치료로 고려. 해외 경로로 구해야 해 TS-1을 써야 할 때 고민해 볼 옵션 (행복방 의견) |
| 키트루다(펨브롤리주맙) | PD-L1, TMB, MSI-H/MMR-d 검사 확인 | 이전 치료 후 진행했고 대체 옵션이 없는 MSI-H/dMMR 췌장암 |

이 외에 주치의 판단에 따라 조합·병용하기도 한다. KRAS G12C에는 소토라십 등 표적약이 있고(세브란스 이희승 교수 강의 정리, 행복방 수록), 2024년 이후 KRAS 표적약 임상이 빠르게 늘고 있다. → [주제별 보기](../../_generated/topics/index.md)

## 표준 항암 순서 (행복방 정리) { #sequence }

- 폴피리녹스 → 젬아 → 오니바이드 → TS-1
- 젬아 → 폴피리녹스 → 오니바이드 → TS-1 (전이되었거나 고령, 몸이 약한 경우, 교수 판단에 따라 젬아로 시작)

!!! note "행복방 생각정리 — 내성 판단이 중요한 이유"
    우리가 제대로 쓸 수 있는 약은 폴피리녹스, 젬아 두 가지다. 내성 판단을 잘못해서 약을 버리면 다시 돌아가지 못한다. 대형병원은 많은 췌장암 환자 데이터로 최대한 타이트하고 합리적으로 내성을 판단한다. 지방 병원 중에는 아직 3차 약인 오니바이드를 취급하지 않거나, 키트루다·린파자를 거의 쓰지 않는 곳이 많다. → [지방 환자의 선택](hospital-tips.md#regional)

### 항암제 발전 순서 (세브란스 이희승 교수 강의, 행복방 정리)

젬시타빈(1996) → 젬+타세바(2007) → 폴피리녹스(2011) → 젬+아브락산(2013) → 오니바이드(2016) → 키트루다(2017) → 린파자(2019) → 소토라십(2021)

- 1세대 세포독성 항암제(설사, 입 헒, 고열, 백혈구 감소, 탈모): 췌장암에 제일 효과 좋은 약은 아직 폴피리녹스·젬아브락산.
- 2세대 표적 항암(키트루다·린파자·소토라십 등): 문제가 되는 암세포만 공격. 제한된 표적 유전자: KRAS(90% 이상 보유), BRCA(5~10%, 백금계·폴피리녹스 반응 좋음).
- 3세대 면역 항암: 몸의 면역체계를 조절해 암세포를 적으로 인식하게 함. 암세포의 "연기"에 속기도 함.
- 제일 효과 좋은 약을 먼저 쓰므로 뒤로 갈수록 효과는 떨어질 수 있다. 항암제 독성 때문에 대부분 휴약을 하게 되므로 좌절할 필요 없다. **식사를 잘하고 컨디션이 좋아야 한다.**

## 약별 주요 부작용 (행복방 정리, 췌담도내과 자료) { #side-effects }

| 약 | 주요 부작용 |
|---|---|
| 젬시타빈 | 골수기능 저하, 발열, 두드러기, 가려움, 탈모, 오심·구토, 변비, 피부색 검게 변함 |
| 시스플라틴 | 오심·구토, 골수기능 저하, 말초신경 이상, 탈모, 신독성(수분 섭취 격려), 이명 |
| 5-FU | 구내염, 설사, 골수기능 저하, 피부 검게 변함, 오심·구토, 수족증후군 |
| 카페시타빈(젤로다, 먹는약) | 수족증후군, 피부 검게 변함, 설사, 골수기능 저하, 구내염, 발열, 구토 |
| 옥살리플라틴 | 말초신경 이상, 오심·구토, 설사, 점막염, 골수기능 저하 |
| 엘로티닙(타세바, 먹는약) | 두드러기, 가려움, 설사, 복통, 오심, 식욕부진, 피로 |
| 에토포시드 | 골수기능 저하, 탈모, 오심·구토, 점막염, 말초신경 독성 |
| 이리노테칸 | 설사, 발열, 탈모, 심·간기능 이상, 오심·구토, 수족증후군 |
| 아브락산 | 오심·구토, 설사, 근육통, 탈모, 말초신경 독성, 골수기능 저하, 발진, 부종 |

항암제 합병증 전반: 위장관(식욕부진, 구내염, 오심·구토, 설사, 변비), 골수 약화(감염, 빈혈, 출혈, 패혈증), 말초신경 이상(근육통·관절통, 손발 저림), 피부·손톱(검게 변함, 손발바닥 갈라짐, 손톱 부러짐), 생식·신장방광(불임, 생리 중단, 혈뇨, 신부전), 심장(심근증, 심부전), 피부궤양(항암제 혈관 외 유출), 수족증후군(손발 벗겨짐, 부종, 통증), 탈모, 피로, 약물 과민반응(두드러기, 홍반, 쇼크). → 대처는 [항암 부작용별 대처](chemo-side-effects.md)

## 항암 용량이 얼마나 줄었는지 계산하기 (RDI) { #rdi }

행복방 문서는 서울대병원 "RDI 계산기"(상대용량강도) 화면과 직접 계산법을 싣고 있습니다. 항암이 밀리거나 용량이 줄면 계획 대비 실제 투여 강도가 떨어지는데, 이를 알고 있으면 주치의와 상담할 때 도움이 됩니다.

**기준 용량 (체표면적 1㎡당)**

| 요법 | 약 | 기준 |
|---|---|---|
| 폴피리녹스 | 옥살리플라틴 85mg · 이리노테칸 180mg · 5-FU 볼루스 400mg · 5-FU 지속주입 2400mg(원문 표기 1200mg) | 2주 간격 |
| 젬아 | 젬시타빈 1000mg · 아브락산 125mg | |

**계산법 (행복방)**

1. 앱스토어에서 "BSA"(체표면적) 계산 앱을 받는다.
2. 환자의 키와 몸무게로 BSA 값을 구한다.
3. BSA × 약의 기준 용량 = 100% 용량.
4. 실제 투약받은 용량 ÷ 100% 용량 = 투여 비율(%).

예: BSA 1.6㎡, 옥살리플라틴 기준 85mg → 100% 용량 136mg. 실제 110mg을 맞았다면 81%.

!!! tip
    원문에 나온 폴피리녹스 농도 계산 사이트(hwang-lab)와 서울대병원 계산기는 주소가 바뀔 수 있어 링크를 싣지 않았습니다. 주치의에게 "이번 차수 RDI가 몇 %인가요"라고 물어보는 것이 가장 정확합니다.
