# 통증 조절

!!! quote "출처: 행복방"
    행복방 문서의 "통증에 대한 잘못된 생각들", "진통제 치료의 원칙", "진통제 조절 흐름도", 그리고 버니님의 경험을 옮겼습니다. 경험 부분은 (행복방)으로 표시했습니다.

## 통증에 대한 잘못된 생각 4가지

1. "암 환자의 통증은 완화시키기 어렵다" → **아니다.** 대부분 완화할 수 있다.
2. "마약성 진통제는 중독 위험 때문에 가능하면 쓰지 말아야 한다" → **아니다.** 통증 조절용 마약성 진통제로 중독되는 경우는 매우 드물다.
3. "통증이 심해질 때를 대비해 진통제를 아껴 두어야 한다" → **아니다.** 통증이 조절될 때까지 용량을 올릴 수 있으므로 아낄 필요가 없다. 참다가 먹으면 더 많은 양이 필요하므로 **통증이 시작되기 전에** 조절하는 것이 효과적.
4. "진통제가 항암 효과를 방해한다" → **아니다.** 전신 상태가 좋아져 오히려 치료에 도움이 된다.

많은 환자가 의료진이 귀찮아할까 봐 아프다는 말을 주저한다. 통증은 본인만 아는 주관적 느낌이므로 **얼마나 아픈지 정확히 표현**해야 적절한 진통제 종류와 용량이 정해진다.

## 통증 표현하는 법

1. 어디가 아픈지
2. 어떻게 아픈지 (날카로운지, 둔한지, 욱신욱신 쑤시는지, 타는 듯한지, 저리는 듯한지)
3. 가끔 아픈지, 하루 종일 아픈지
4. 어떨 때 아프고 어떻게 하면 덜 아픈지
5. 지금 먹는 진통제가 통증을 어느 정도 줄여 주는지
6. 지금 또는 최근 24시간 동안 얼마나 아팠는지 **0~10점**

## 통증이 생기는 이유

- 암 자체: 종양이 신경, 뼈, 장기를 침범
- 암 치료: 급성 통증, 항암제 부작용, 방사선 부작용

대부분 진통제와 온·냉찜질, 이완요법 같은 비약물 요법으로 조절된다. 듣지 않으면 방사선 요법, 신경차단술, 신경외과적 수술도 가능하다. 췌장암 통증에는 **복강신경총 차단술**이 효과적인 선택지다. → [통증 악화 응급 기준](../emergency/pain-crisis.md)

## 진통제 치료의 원칙

- **아프기 전에** 미리 복용한다.
- 주사보다 **먹거나 붙이는** 진통제가 편하고 경제적이다.
- **단계적으로** 사용한다.

### 진통제 종류

| 단계 | 종류 | 설명 |
|---|---|---|
| 약한 통증 | 비마약성 진통제, 소염진통제 | 습관성·신체의존 없음. 뼈·근육 통증에 특히 효과 |
| 중등도 | 약한 마약성 진통제 | |
| 심한 통증 | 강한 마약성 진통제 (서방형 8~24시간 지속) | 가능하면 한 종류를 쓰고, 부작용이 있거나 효과가 없으면 다른 종류로 바꾼다 |
| | 붙이는 진통제 (3일 지속) | 아래 "패치 주의" |
| | 속효성 진통제 | 돌발 통증에 빠르게 |
| 보조 진통제 | 신경병증성 통증(저리거나 타는 듯한 통증)용 | 단독 또는 마약성과 함께. 척추 전이 신경통, 대상포진 후 신경통, 항암제 손발 저림에 사용. 부작용: 현기증, 졸음, 입마름 |

### 마약성 진통제 조절 흐름 (행복방 수록 흐름도를 글로 옮김)

통증 4~10점이고 경구용 마약성 진통제를 쓸 때:

1. **처음 사용**: 속효성 진통제(황산모르핀 7.5~15mg 또는 옥시코돈 5~10mg) 투여.
   **현재 사용 중**: 지속형은 그대로 복용하고, 속효성(하루 총 용량의 10~20%)을 추가.
2. **1시간 후 통증과 부작용 재평가**
   - 4~6점으로 감소 → 같은 용량 반복
   - 0~3점으로 감소 → 2~3시간 후 재평가
   - 변하지 않거나 심해짐 → 용량을 2배로 늘림
3. 취침 전에는 지속형 제제를. 통증이 잘 조절되는 시점(0~3점)에서 24시간 동안 복용한 총 용량을 계산해 지속형 제제로 바꾼다.
4. 지속형 하루 총량을 2~3회로 나눠 규칙적으로 복용해 통증을 예방하고, 돌발 통증이 생기면 언제라도 속효성을 복용한다.

(용량은 의료진이 정합니다. 집에서 임의로 2배로 올리지 마세요.)

## 진통제 부작용과 대처

| 부작용 | 대처 |
|---|---|
| 변비 | 예방적으로 **변 완화제를 함께** 복용. 수분, 섬유질, 적당한 운동 → [변비 대처(행복방)](chemo-side-effects.md#bowel) |
| 울렁거림·구토 | 대개 1~2주면 감소. 심하면 항구토제 병용 또는 다른 진통제로 변경 |
| 졸음 | 처음 복용하거나 용량을 늘릴 때. 며칠 내 감소. 운전·기계 조작 주의 |
| 배뇨 곤란 | 전립선 비대증 환자에서 흔함. 배뇨 돕는 약 추가 또는 진통제 변경 |
| 호흡이 느려짐 | 드물지만 가장 심각. 처음 사용 시 많은 용량을 짧은 시간에 정맥 주입할 때. 경구 복용에서는 거의 없음 |

## 패치형 진통제(펜타닐) 주의 (행복방 경험) { #patch }

- 효과가 모르핀의 백 배 수준으로 강하고 내성·의존성·탐닉성 위험이 있으며, 과량 사용 시 호흡곤란으로 사망에 이를 수 있다. 의존하게 되면 나중에 어떤 진통제도 듣지 않게 될 수 있다. **조절되지 않는 통증에만** 쓰고 남용하지 않는다.
- 행복방 가족은 통증이 없는데도 매 항암마다 처방된 패치를 산쿠소(구토 방지) 패치로 착각해 붙인 적이 있다. **내가 붙이는 패치가 무엇인지 확인.**
- 폴피리녹스 한 번에 암성 통증이 사라졌다고 좋아하던 분이 지금은 진통제를 안 드신다. 항암이 진행되면 통증이 자연히 사라지는 경우가 많으니 **너무 센 진통제에 의존하지 말고** 통증이 없어지면 서서히 줄인다.

## 비약물 요법

| 방법 | 요령 |
|---|---|
| 냉·온찜질 | 아픈 부위에 얼음주머니나 따뜻한 물주머니. 한 부위 15~20분 이상 대지 말고 1시간 후 반복. 감각이 둔하거나 순환이 안 되는 부위는 주의. 물주머니는 수건으로 싸서 화상 방지 |
| 마사지 | 아픈 부위 주변을 마사지하거나 가볍게 두드려 순환을 도움 |
| 이완·상상 요법 | 편안히 앉거나 누워 기분 좋은 풍경, 행복했던 기억을 떠올림. 심호흡 함께 |
| 기분 전환 | 음악, TV, 산책, 가족·친구와 대화 |
| 운동 | 엔돌핀 분비로 통증 감소. 통증 정도에 맞춰 속도를 정하고 스스로 하려 노력. 뼈가 약해진 경우 무리한 운동은 피함 |
| 고정 | 움직일 때 심해지면 보조기나 복대로 고정하거나 휴식 |
| 기타 | 뼈 전이, 골절, 뇌 전이, 척수신경 압박 시 방사선치료. 진통제로 안 되면 신경차단술, 신경외과 수술 |

## 뼈 전이 (행복방 의견) { #bone }

> 뼈 전이 자체로는 생명의 위협이 없지만 그 통증 때문에 결국 다 포기하게 됩니다. 항암제가 잘 침투하지 못합니다. 조금이라도 발견되면 **바로 방사선**으로 지지셔야 합니다. "지켜보자" 하면 그냥 방사선 하겠다고 하세요. 그리고 **엑스지바**(데노수맙)를 맞게 해달라고 하세요. 혈종과에서 처방해 주지 않으면 신경외과를 예약해서라도 맞으세요. 그래도 안 되면 동네 가정의학과에서 비스포스포네이트(골다공증 예방약)를 처방받아 드세요.

(엑스지바·비스포스포네이트는 뼈 전이 합병증 예방에 쓰이는 약이며 적응증·급여 조건이 있으므로 주치의와 상의하세요.)
