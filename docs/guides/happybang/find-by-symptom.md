# 증상·상황으로 찾기

지금 겪는 문제를 아래에서 찾으세요. 굵은 글씨는 **먼저 확인할 응급 기준**입니다. 검색창에 "토해요", "열나요", "변이 안 나와요"처럼 쳐도 됩니다.

!!! danger "이 중 하나면 지금 바로 119 또는 응급실"
    38℃ 이상 열 + 항암 중 · 피를 토함/검은 변 · 숨이 참 · 의식이 흐림 · 극심한 복통 · 12시간 넘게 물도 못 마심 · 한쪽 다리 붓고 가슴 통증
