# 보조제 이야기

!!! danger "꼭 읽어 주세요"
    이 페이지는 행복방 환우·보호자들이 **직접 공부해서 선택한 것을 공유**한 내용입니다. 원문도 "권유하는 글이 아님"을 밝히고 있습니다. 여기 적힌 효과 중 상당수는 **사람 대상 임상시험으로 입증되지 않았고**, 일부는 항암제와 충돌하거나 출혈 위험을 높일 수 있습니다. 시술·수술 전에는 반드시 복용 중인 보조제를 의료진에게 알리세요.

!!! quote "출처: 행복방"
    원문의 "많이 드시는 보조제 목록"과 네이버 카페 5years의 "췌장암 보조제 정리" 요약을 바탕으로 했습니다. 구매처 안내와 해외 구매 경로는 싣지 않았습니다.

## 행복방에서 말하는 "보조제를 대하는 자세"

- 주치의(혈액종양내과)에게 "멜라토닌 먹어도 되나요?"를 묻는 분이 많은데, 주치의는 항암약을 공부한 분이지 보조제 성분에는 관심도 없고 모른다고 보면 된다. 보조제는 직접 공부해서 스스로 선택하는 것. (행복방 의견)
- 영양교육실은 이것도 저것도 먹지 말라 하고, 주치의는 그러다 굶어 죽는다고 다 먹으라 한다. 보조제도 비슷한 맥락.
- 6개월에 한 번 정도 피검사 후 부족한 것을 보충한다.
- 해외 제품을 많이 쓰는 이유는 국산이 비싸고 함량이 낮다는 경험 때문.

## 행복방에서 많이 복용한 보조제

| 보조제 | 행복방이 기대한 역할 | 행복방이 적어둔 주의 |
|---|---|---|
| **비타민D** | 췌장암의 필수 보조제로 봄. 세포 분화 늦춤, 암세포 부착성 저하(2000년대 후반 학회에서 효과 인정이라고 기술) | 매일 먹는 약이 많으므로 주사로 보충하면 편함. 액상 5000IU 이상 몇 달 꾸준히 |
| **노자임** (췌장효소) | 췌장에서 분비되는 소화효소 부족으로 생기는 지방변 예방. 지방·단백질·전분 소화를 도와 체중 감소를 막음 | 처방약. [소화 처방](chemo-side-effects.md#digest) |
| **MCP** (변형 감귤 펙틴) | 암세포의 끈적한 부분을 상쇄해 다른 장기 전이를 방해(100%는 아님). 청귤 추출 | **항응고 작용**이 있어 출혈이 있거나 시술할 때 복용 중지. 처음 복용량이 많아 가루가 수월 |
| **밀크시슬**(실리마린) | 간 보호. 하루 400mg 정도 한 알 | 밀크시슬 함량이 아니라 실리마린 함량을 볼 것 |
| **멜라토닌** | 수면 유도. 항암 효과가 있다고 보며 보통 10mg에서 시작해 고용량을 쓰기도(행복방 가족은 30mg) | 2mg은 효과가 거의 없다고 함. 국내에서 고용량 합법 구입이 어려움 |
| **우벤자임** (전신 효소) | 단백질 소화력, 염증 억제. 암세포 간질세포를 무력화해 면역세포가 효율적으로 작동한다고 봄 | 공복 장기 복용 시 위염 가능. 2달 복용 후 1달 쉬는 패턴. 항암 당일은 피함 |
| **아르테미시닌** (개똥쑥) | 철분에 결합해 암세포의 산소 공급을 방해한다고 봄 | 간독성 있음. 항암제 충돌에 관한 연구 없음. 가려움·발진, 장기 사용 시 뇌출혈·뇌졸중·위궤양·소화불량 보고 |
| **수용성 커큐민** (강황) | 면역 조절, 암세포 증식 억제. 흡수율이 핵심이라 수용성 제품 | **항응고 작용**: 출혈·시술 시 중지. 항산화 작용으로 항암과 충돌 우려(특히 독소루비신·시클로포스파미드) |
| **포포(PAWPAW, 아세토제닌)** | 다제내성(항암제 내성) 암세포의 ATP 공급을 차단한다고 봄. 항암 중단 환자에서 생존 연장 사례가 있다고 기술 | 부작용 구토·설사. 임산부·수유부 금지. 하루 3번 2알이 권장이나 1알부터 천천히. 그라비올라·파파야와는 전혀 다른 물질. 포포 잎은 신경독성으로 위험. 코엔자임Q10과 상극 |
| **베타글루칸** | 자체 항암 기능은 없고 면역 보조제. 항암 시 삶의 질 개선 | 과도한 염증 상태에서 암을 촉진한다는 존스홉킨스 연구 보고 있음 |
| **스피루리나** | 말초신경병증에 효과 | 간독성. 항암제 충돌 연구 없음 |

## 항암 중 금기로 적힌 것

- **코엔자임Q10**: "항암 중에는 절대 피해야 할 금기 보조제". 매우 강력한 항산화 물질.
- 고농도 비타민C·E·A, 셀레늄, 글루타치온, 베타카로틴, 녹차 카테킨 등 항산화제 → [항산화 영양제 제한](chemo-side-effects.md#antioxidant)

## 이 사이트의 입장

위 표의 "기대한 역할" 대부분은 세포·동물 실험이나 소규모 보고에 근거하며, 췌장암 환자에서 생존을 늘린다는 무작위 임상 근거는 없습니다. 비타민D 결핍 교정, 췌장효소(노자임) 보충처럼 의학적으로 받아들여진 것과 나머지를 구분해 보시기 바랍니다. 새 근거가 나오면 이 사이트의 [지지요법·삶의질](../../_generated/categories/supportive.md) 카테고리에 자동 수집됩니다.
