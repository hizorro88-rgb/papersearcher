# 항암 부작용별 대처

!!! quote "출처: 행복방"
    폴피리녹스·젬아 항암을 받은 환우 가족의 경험과 행복방 회원들의 조언을 정리한 것입니다. 약 이름은 참고용이며 처방은 담당 의료진이 결정합니다. 원문: "톡방에 상주하시면서 하나하나 배워나가세요."

**가장 주의해서 대비할 부작용(폴피리녹스 기준)**: 구토·오심, 손발 냉감·저림, 설사 또는 변비, 미각 이상, 식욕 저하, 구내염. 대비하기 힘든 부작용: 혈구 저하. (행복방)

## 부작용은 언제 오나 { #timeline }

행복방 문서에 실린 서울아산병원 「항암제 부작용 관리」 안내도를 글로 옮겼습니다. (원출처: 서울아산병원 안내 자료, 행복방 문서 수록)

| 항암 후 시기 | 흔한 부작용 | 대처 요점 |
|---|---|---|
| 1~2일 | 메스꺼움·구토 | 식사는 가볍게, 구토 방지제 복용, 담백한 음식 소량. 구토가 심해 약을 못 먹으면 의료진 상의 |
| 2~5일 | 식욕부진, 변비, 설사 | 소량씩 자주 먹기, 충분한 수분. 변비엔 섬유질·운동, 설사엔 자극 없는 음식과 전해질 보충 |
| 7~10일 | 구내염, 백혈구 감소 | 부드러운 음식·입안 청결. 날것 피하기, 사람 많은 곳 피하기, **발열 시 즉시 병원** |
| 2~3주 | 탈모 | 순한 샴푸, 두피 보호 |

## 1. 구토·오심 { #vomit }

> "구토나 오심이 오고 난 뒤에는 걷잡을 수가 없다. 먹을 수가 없고 물도 다 토하니 구토방지제도 먹을 수가 없게 된다." (행복방)

- **미리 막는 것이 핵심.** 항암 하루 전(시작 24시간 전) **산쿠소 패치**를 붙이고, 항암 전 먹는 약(맥페란, 에멘드, 조프란 등)을 한 번 더 먹는다. 패치는 비급여지만 지속 시간이 길다.
- 호중구가 낮아 항암이 자주 밀리는 분은 비싼 패치를 버릴 수 있으니, 항암 당일 아침 먹는 약을 먹어두고 병원에서 호중구 확인 후 패치를 붙이는 방법이 있다.
- 전처치 주사 **덱사메타손(스테로이드)** 때문에 딸꾹질이 생길 수 있다. 지속되면 병원에 알리고 빼는 것을 고려.
- **이미 구토가 시작됐다면** 가까운 2차병원이나 내과에 가서 "항암으로 인한 구토·오심"이라고 말하고 주사제로 가라앉힌다. 속이 가라앉으면 **증상 전에 약을 챙겨 먹는다.**
- 빈속이면 울렁거림이 더 심하다. 조금이라도 음식을 넘기도록 한다.
- 1차 항암 때 "증상 없이는 약 처방 못 한다"는 경우가 있다. 이때는 집 근처 2차병원·내과에서 처방받고, 다음 항암 때 구토로 식사를 못 했다고 호소해 처방받는다.
- 항암 초반에 심하게 구토를 겪으면 병원 건물만 봐도 미식거리는 증상이 올 수 있다. 이때는 **신경안정제(아티반)** 처방을 받으면 훨씬 안정적으로 항암을 유지하고 수면의 질도 올릴 수 있다. 잘 버티면 조금씩 줄인다.
- 구토·오심은 처음에 심하고 차수가 뒤로 갈수록 완화됐다. (행복방 경험)
- 주사 속도를 늦추니 구토·오심이 현저히 줄었다. → [알레르기·주사 속도](#allergy)

!!! note "행복방 생각정리"
    췌장암 환자는 못 먹으면 데미지가 몇 배로 커진다. 첫 항암에서 심한 부작용을 겪으면 항암을 포기하거나 의욕을 잃을 수 있다. **꼭 1차부터 잘 대비해야 한다.**

## 2. 설사와 변비 — 둘 다 약을 미리 받아두기 { #bowel }

첫 항암 때 설사가 올 수 있어 전처치로 설사 방지제를 놓는데, 설사 부작용이 없는 환우는 **극심한 변비**를 겪는다. 마약성 진통제도 변비를 부른다. 설사약과 변비약 **두 가지 모두** 처방받아 바로 대처한다. (행복방)

### 설사

- 전해질 부족에 대비해 **이온음료**(토레타, 게토레이)를 준비한다. 원문은 포카리는 자몽이 들어가 좋지 않다고 한다.
- **스멕타**(디옥타헤드랄스멕타이트)는 **반드시 식간에**. 흡착성이 있어 식후에 먹으면 다른 약 흡수를 방해한다. 하루 3번, 초기 3일은 2배로 늘려도 된다고 한다.
- 초기에 잡히지 않으면 **로프민**(로페라미드)을 스멕타와 2시간 띄워 교차 복용: 식간 스멕타 → 설사 확인 → 2시간 뒤 로프민 → 식간 스멕타 → … 
- **설사가 멈춘 것 같으면 로프민을 반드시 중지**해야 변비로 고생하지 않는다.

### 변비

- 병원 변비약이 약하면 **딥푸룬주스**(올리브영)를 두 통 정도 구비. 한꺼번에 많이 마시면 배가 요동치니 조금씩.
- "나오겠지" 하지 말고 적극 대처. 돌처럼 굳으면 관장도 안 듣는다.
- 변비약 세기 (행복방 "벼리님" 정리):

| 단계 | 약 | 종류 | 특징 |
|---|---|---|---|
| 1 | 마그밀 | 팽창성 | 장기 사용해도 습관성 없음. 효과는 가장 약함 |
| 2 | 듀파락 | 삼투성 | 변을 묽게. 습관성 중간. 식전 공복 복용 |
| 3 | 둘코락스 | 자극성 | 점막 자극, 습관성 가능, 효과 빠름. 자기 전 2알 → 약 8시간 뒤 신호. 좌약형도 있음. 약국 변비약은 대부분 자극성 |
| 4 | 관장약 | 자극성 | 급할 때 가장 강력. 습관성 가능 |

- 관장으로도 안 될 때(변이 항문에 걸려 힘으로 안 나올 때)의 최후 방법: 관장약 넣고 10분 이상 기다린 뒤, 작은 찻숟가락에 윤활제를 발라 항문에 걸린 딱딱한 덩어리를 꺼내 주면 이후엔 환자 힘으로 나올 수 있다. (행복방 경험. 출혈·통증이 있으면 병원으로)

## 3. 손발 냉감·저림 (말초신경병증) { #neuropathy }

- **리리카캡슐, 심발타, 뉴론틴**은 "악화 방지"용이다. 개선이 아니라 더 심해지지 않게 하는 예방이므로 **항암을 그만할 때까지 계속** 먹는다. 어르신들이 "별 효과 없다"며 안 드시는 일이 생기니 꼭 확인. 행복방 가족은 세 가지 다 써봤고 뉴론틴이 효과가 좋았다.
- 집에서 꾸준히 **족욕**, TV 보며 **지압판 걷기**, **마사지**를 해야 진행을 늦출 수 있다.
- **젬아**는 말초신경증 관리가 특히 중요. 몸살·발열·손발 저림이 많고 보통 항암 이틀 후 몸살 기운에 타이레놀을 먹기도 한다. 건식 반신욕기, 지압 신발로 관리. ("따뜻한 봄날님" 조언)
- 옥살리플라틴(폴피리녹스) 부작용으로 **찬 음식이 목에 걸려** 못 먹는 분도 있으니 유의.

## 4. 식사가 매우 힘들어질 때 { #appetite }

> "입에 들어가는 게 다 모래 같다." (행복방)

- 대체로 **누룽지, 동치미, 오이냉국, 메밀국수, 수박, 냉면, 식혜, 탄산수, 생강차** 등 새콤·시원·구수한 것은 조금씩 넘어간다. 누룽지 끓인 것은 보통 잘 드신다. 밥은 거의 안 넘어간다. 떡, 뉴케어 종류별로 하나씩 사서 입에 맞는 것 찾기.
- **냄새에 매우 민감**하다. 환자가 직접 조리하지 않아야 더 먹을 수 있다.
- 적은 양을 자주. 힘들면 **식욕촉진제 메게이스**라도 처방받아 체중 손실을 최소화한다. 메게이스는 합성 스테로이드 호르몬의 일종이라 **단기간**만 쓰고 스스로 입맛을 찾도록 한다. 장기 투여 시 쿠싱증후군으로 부종이 심해지거나 당뇨가 악화될 수 있으니 혈당 체크. "무서운 약 같지만 암환자에게 악액질이 더 무서우니 시기적절하게 사용."
- 한 입 먹고 버리더라도 입에 들어가는 걸 찾아둔다. 그래야 버틴다.
- 구체적인 음식 목록은 [식사와 영양](nutrition.md).

### 음식 섭취가 너무 힘들면 영양 주사 { #nutrition-iv }

- 가까운 2차병원·내과에서 **아미노산 수액**(가방 항암 중)이나 **오마프원페리주**(항암 주사 뽑은 뒤) 같은 영양제를 맞는다. 오마프원은 **천천히**(한 팩 최대 24시간).
- "항암 부작용으로 밥 한 톨, 물 한 모금도 못 넘겼다"고 말해야 중증 적용이 가능하다.
- 주의: 후반에 오마프원을 계속 맞던 환우에게 **폐와 심장에 물이 차는** 일이 있었다. 연속으로 많이 맞으면 이런 부작용이 있을 수 있으니 매우 천천히. (행복방 경험)

## 5. 구내염 — 진행되기 전에 잡기 { #stomatitis }

구내염이 진행되면 밥을 못 먹고, 힘이 빠지면 운동을 못 한다. (행복방)

- 예방: **식염수로 자주 가글**, 구내염 예방용 **프로폴리스 스프레이**.
- 병원에서 가장 많이 처방하는 것은 **헥사메딘**(항균), **탄튬**(소염진통) 가글. 식사 전 탄튬 가글(입안을 얼얼하게 하는 성분)로 마취 효과를 내고 식사한다.
- 행복방 의견: 헥사메딘은 잘 안 듣는다. **초기에** 아프니벤큐, 뮤테라실, 카미스타드엔겔 등으로 확 잡아야 칸디다증으로 진행되지 않는다. 초기 진화에 실패하면 입안이 허옇게 변하며 목까지 진행된다.
- **칸디다성 구내염**(곰팡이)에는 **니스타틴이나 디푸루칸**을 써야 낫는다. 진행 상황에 맞게 바로바로 약을 쓴다.

## 6. 통증 조절 { #pain }

- 마약성 진통제라면 어떻게든 참겠다며 거부하는 어르신이 있는데, 바람직하지 않다. 아프면 먹기도 움직이기도 싫어져 악순환. **통증이 없어야 밥을 먹고 운동하고 잠을 자서 항암을 밀리지 않고 받는다.**
- 꼭 마약성이 아니어도 **덱시부프로펜, 나프록센** 같은 소염진통제가 듣는 경우가 의외로 많다. 한 통씩 구비해 잘 듣는 것을 찾는다.
- **패치형 진통제(펜타닐)는 주의.** 효과가 모르핀의 백 배 수준으로 강하고 내성·의존성 위험이 있으며 과량 시 호흡곤란으로 사망할 수 있다. 조절되지 않는 통증에만 쓰고, 나중의 심한 암성 통증을 위해 남용하지 않는다. 행복방 가족은 통증이 없는데도 매 항암마다 처방된 패치를 산쿠소 패치로 착각해 붙인 적이 있다.
- 항암이 진행되면 통증이 자연스럽게 사라지는 경우가 많다. 통증이 없어지면 **서서히** 진통제를 줄인다.
- 자세한 원칙·부작용·비약물 요법은 [통증 조절](pain.md).

## 7. 혈구 저하 — 항암이 밀리는 가장 큰 이유 { #blood }

호중구가 모자라면 항암이 1주일씩 미뤄진다. 무조건 **잘 먹고 잘 자야** 한다. (행복방)

- 행복방에서 꼽는 음식: 소고기 안심, 문어, 비트, 바나나, 골드키위, 염소고기, 추어탕, 장어, 삶은 계란, 닭발곰탕. (레시피는 [식사와 영양](nutrition.md#chicken-feet))
- **지방 환자**: 항암을 위해 몇 시간 올라와 헛걸음하지 않으려면, 하루 이틀 전 동네 2차병원에서 혈구를 확인하고 호중구가 떨어졌으면 **류코스팀**을 맞거나 조금 길게 유지되는 **뉴라스타**를 자비로 맞는다. 혈액암협회에서 약제비 지원을 받을 수 있다.
- **호중구 수치는 폴피리녹스와 연관**이 있다. **젬아는 혈소판 수치**와 연관이 있으니 젬아 하시는 분은 호중구에 너무 민감하지 않아도 된다.
- 나중에 본원에서 안 해주는 **수혈**을 받을 수 있도록 가까운 종합병원을 하나 뚫어 두면 좋다.
- **촉진제로 오른 호중구는 "뻥튀기"라고 생각하라.** 절대 날것·회·게장을 먹지 않는다. 이걸 믿고 회를 먹었다가 열 오르고 CRP 오르고 항암 밀리고 한 달 입원해 항생제를 맞을 수 있다.
- 사례: 싸이모신(티모신 알파) 주사를 동네 내과에서 일주일에 두 번 정도 맞는 경우도 있다(원가 9만 원대). 효과는 검증된 치료가 아니므로 주치의와 상의.

### 절대호중구수(ANC) 계산 { #anc }

행복방 문서의 계산식: **ANC = 백혈구(WBC, ×1000) × 호중구(Neutrophil) %**

예: WBC 4.53, 호중구 45% → 4.53 × 1000 × 0.45 = **2,038** → 항암 가능 수준. 병원마다 기준이 다르나 보통 1,500 이상을 요구한다.

### 항암제 합병증으로 보는 혈액 수치 (행복방 정리)

| 수치 | 정상 범위 | 떨어지면 |
|---|---|---|
| 백혈구 | 4,000~10,000 | 면역력 저하 → 감염. **고열 38℃ 이상, 오한 → 응급실**. 해열제 임의 투여 조심 |
| 적혈구(혈색소) | 12~16 | 빈혈 → 어지러움, 호흡곤란. 심하면 응급실 |
| 혈소판 | 150,000~400,000 | 응고·지혈 안 됨 → 혈변, 혈뇨, 검은 변, 토혈, 피가 멈추지 않음 |

고열 시 해열제(타이레놀 2알 등) 복용 후 **2시간이 지나도 열이 떨어지지 않으면 응급실**. (행복방)

## 8. 간수치 관리 — "간 관련 3종 세트" { #liver }

간과 신장은 망가지면 회복되지 않는다. 항암을 하다 보면 어느 정도 간수치 상승이 따라온다. (행복방)

- 처방: **우루사, 고덱스** (AST, ALT, ALP, GGT가 기준치 이상이면 처방된다). 실질적으로 간수치를 내려준다.
- 독소로부터 간세포를 보호한다는 **실리마린**(밀크시슬). 국내 처방약은 레가론 140mg 하루 3회. 행복방은 해외 직구 제품 하루 400mg 1회를 썼다(밀크시슬 함량이 아니라 실리마린 함량을 본다).
- 보수적인 주치의라면 "오래오래 항암하고 싶어요, 간수치가 좀 높던데 우루사나 고덱스 처방해 주시면 안 될까요?"라고 청해 본다. 그래도 안 되면 동네 2차병원에서 피검사 후 처방받는다.

## 9. 항암 중 항산화 영양제 제한 { #antioxidant }

항암 작용을 방해할 수 있으므로 **고농도 비타민C, 비타민E, 비타민A, 셀레늄, 코엔자임Q10, 글루타치온, 베타카로틴, 카테킨(녹차)** 등은 제한. 실리마린이나 커큐민도 항산화 작용을 하지만 항산화율이 낮은 편이라 충돌이 적다고 한다. (행복방) → [보조제 이야기](supplements.md)

## 11. 갑자기 간지럽거나 목이 붓는 느낌 — 약물 알레르기 { #allergy }

- 약물 알레르기 반응이다. 참지 말고 **바로 주치의에게** 말한다.
- 행복방 가족은 7차부터 이 증상이 생겨 **주사 속도를 늦췄고**, 늦추니 구토·오심도 현저히 없어졌다. "항암은 천천히 맞는 게 좋다."
- 반응이 없어도 천천히 넣어 달라고 매번 말하고, 조금이라도 이상하면 간호사에게 확인한다. 대형병원에서도 실수가 있다. **내 약이 맞는지, 약 이름, 용량, 속도를 반드시 확인.**

## 12. 복부 위치별 의심 증상 { #abdomen }

원문은 "복부 위치별 의심 증상" 그림을 담고 있으나 그림 내용은 이 문서에 옮기지 않았습니다. 췌장암 증상의 일반 정보는 [수술 관련 – 증상](surgery.md#symptoms)을 보세요.

## 소화불량·위장 증상 처방 (행복방 회원 정리) { #digest }

항암 후유증으로 역류성 식도염, 위경련, 상복부·명치·가슴·식도 통증이 있는 분들의 서울아산병원 처방 예 ("쥬마마님", "소영님" 조언):

| 약 | 역할 |
|---|---|
| 파자임(위) | 모자란 소화효소 보충, 음식이 잘 소화되게, 가스 제거 |
| 노자임(장) | 장이 더부룩하고 소화가 안 될 때, 지방변 볼 때. 췌장효소 보충으로 지방·단백질·전분 소화를 도와 체중 감소를 막음 |
| 모티리톤 | 소화불량으로 더부룩함 해소. 복통(쥐어짜는 통증), 위경련에는 비스듬히 누워 배를 따뜻하게 |
| 넥시움(PPI) | 위산 억제. 가슴 통증, 목을 콕콕 찌름, 목 이물감, 쉰 목소리는 암성 통증이 아니라 식도염 증상 |
| 라미나지액 | 위 점막 생성 및 보호 |
| 애니틴 서방정 | 위 운동 조절 및 경련 완화 |

조합 예: 넥시움 + 모티리톤 + 애니틴 + 라미나지액 + 노자임 (통증이 잘 잡히는 편). 체했을 때는 편의점 **닥터베아제(주황색)**. 급할 때 소화불량에는 노란색 닥터베아제.

## 그 밖의 증상별 약 (행복방 정리) { #misc }

| 증상 | 행복방에서 쓴 약·대처 |
|---|---|
| 구토·오심 | 맥페란, 에멘드, 산쿠소 패치, 아킨지오. 이미 시작됐으면 2차병원·응급실에서 맥페란·에멘드 주사 |
| 소화불량 | 파자임 처방 또는 닥터베아제 |
| 피부염·발진·가려움 | 지르텍(알레르기성), 보습. 발진에 리도맥스 ("못냔이님") |
| 설사 | 스멕타 → 안 멈추면 2~3시간 간격 로프민 교차. 멈추면 바로 중단 |
| 변비 | 듀파락이지시럽 → 딥푸룬주스, 약국 '쾌변' |
| 식욕부진 | 메게이스 |
| 이석증 | 천장이 돌거나 벽이 움직이는 어지럼증. 이비인후과 협진(귓속 돌 조절 치료) 또는 맥페란 복용으로 서서히 호전 |
| 말초신경증 | 리리카캡슐, 심발타, 뉴론틴 |
| 간 보호 | 레가론(실리마린), 고덱스, 우루사 |
| 구내염 | 초기 아프니벤큐·뮤테라실·카미스타드엔겔 → 칸디다증 진행 시 니스타틴·디푸루칸 |
| 림프부종 | 압박스타킹(하루 종일), 수면 시 다리를 심장보다 높게. 한번 생기면 치료가 어려우니 초기 대처 → [림프부종](emergency-manual.md#lymphedema) |
| 감기 증상 | 콜대원 |
| 욕창 | 마데카솔 분말 ("못냔이님") |
| 입술 포진 | 아시클로버 크림(바이락스클리어: 아시클로버+하이드로코르티손) + 아시클로버정 |
| 어지러워 휘청 | 항암 후 혈색소 저하로 인한 빈혈일 수 있음. 침대에서 일어날 때 허리와 머리를 숙이고 30초 기다리면 어지러움이 가심. 철분 많은 해조류(파래, 김, 미역귀), 소고기, 굴, 버섯 ("타이앤님") |
