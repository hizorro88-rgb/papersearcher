# 응급 매뉴얼

!!! danger "응급이면 119"
    아래는 상황을 알아보는 데 도움을 주는 자료입니다. 의식 변화, 호흡곤란, 38℃ 이상 발열(항암 중), 멈추지 않는 출혈은 바로 119. 증상별 응급 기준은 [응급 가이드](../emergency/index.md)에 있습니다.

!!! quote "출처: 행복방"
    행복방 문서의 "응급상황 매뉴얼"(패혈증·혈전·섬망·뇌졸중·림프부종, 원출처: 서울대병원·서울아산병원·충남대병원 건강정보), "체온체크 시 참고사항", "활력징후", "응급실 혈압기계 보는 방법(쥬마마님)", "응급실에 보호자로 갈 때 꿀팁 5"를 옮겼습니다.

## 활력징후와 체온 기준 { #vital }

| 항목 | 정상 범위 (행복방 정리) |
|---|---|
| 체온 | 36.5~37.2℃ |
| 혈압 | 수축기(위) 120mmHg 미만, 이완기(아래) 80mmHg 미만 |
| 맥박 | 분당 60~100회 (남성이 여성보다 조금 빠름) |
| 호흡 | 분당 12~16회. 횟수와 함께 호흡곤란 여부, 숨 쉬는 모양을 본다 |

**측정 부위별 정상 체온**: 귀(고막) 35.8~37.8℃ · 입안 35.5~37.5℃ · 겨드랑이 35.3~37.3℃ · 항문 36.6~37.9℃. 65세 이상 귀 체온 정상 범위 35.8~37.5℃.

항암 중 발열 기준은 [항암 중 발열](../emergency/fever-neutropenia.md). 해열제 복용 후 2시간이 지나도 열이 안 떨어지면 응급실. (행복방)

## 응급실 모니터 읽는 법 ("쥬마마님" 교육) { #monitor }

응급실 침대 옆 모니터의 숫자는 보통 위에서부터:

| 색 | 표시 | 뜻 |
|---|---|---|
| 초록 | HR | 심박수(심전도). 분당 60~100 정상 |
| 하늘색 | SpO2 | 산소포화도. 95~100% 정상, 90% 아래면 위험 |
| 빨강 | ABP / NIBP | 혈압(동맥혈 또는 커프). 예 120/75 (평균 93) |
| 노랑 | RR | 호흡수. 분당 12~20 정상 |

## 패혈증 { #sepsis }

**의심 징후** (두 가지 이상이면 패혈증 가능): 체온 38℃ 이상 또는 36℃ 이하 · 호흡수 분당 24회 이상 · 심박수 분당 90회 이상 · 혈액검사에서 백혈구 증가 또는 현저한 감소.

**중증이면**: 의식이 흐려짐, 저혈압, 소변량이 줄며 쇼크, 피부가 시퍼렇게 보임.

**CRP 수치** (염증 지표): 정상 0.5~1.0mg/dL(5~10mg/L) 이하. 1mg/dL 정상, 2mg/dL 심한 염증 가능, 3mg/dL 이상 급성 염증·중증, 15mg/dL 이상 고혈압·당뇨 동반 시 위험, 30mg/dL 이상 암·심근경색·간경화 의심 (행복방 수록 자료).

**대처**: 집에서는 방법이 없다. **즉시 병원으로.** 신체검진·혈액검사·영상 후 적절한 항생제. 균 배양에 3~5일 걸리므로 결과 전에 경험적 치료를 한다. 농양이나 괴사 조직, 인공 삽입물이 있으면 제거를 고려. 혈압을 유지하고 조직에 산소를 공급.

## 혈전 { #thrombosis }

**의심 징후**: 극도의 피로감, 호흡곤란, 가슴 통증, 발열·식은땀·현기증, 심박수 증가, 종아리 통증. 혈전 위치에 따라 증상이 다르다.

| 종류 | 증상 |
|---|---|
| 동맥 혈전 – 급성 심근경색 | 가슴 통증, 호흡곤란, 의식 소실 |
| 동맥 혈전 – 뇌졸중 | 두통, 의식 소실, 운동·감각 이상, 성격 변화, 시력 저하, 경련 |
| 동맥 혈전 – 급성 말초동맥 폐쇄 | 팔·다리 통증, 창백, 차가워짐 |
| 정맥 혈전 – 심부정맥혈전증 | 다리 붓고 아픔. 폐 혈전 동반 시 호흡곤란, 가슴 통증, 의식 소실 |
| 폐 혈전증 | 호흡곤란, 가슴 통증, 의식 소실 |
| 간문맥 혈전증 | 복수, 전신 부종 |
| 급성 신장정맥 폐쇄 | 혈뇨, 단백뇨, 소변량 감소 |
| 뇌정맥동 혈전증 | 두통, 의식 소실, 운동·감각 이상 |
| 중심망막정맥 폐쇄 | 시력 저하 |

**대처**: 동맥 혈전은 응급 수술(혈전 제거) 또는 시술(혈전 제거술, 스텐트)로 혈류를 신속히 정상화. 정맥 혈전은 대부분 약물 치료 병행: 섬유소 용해제(유로키나아제 등), 항응고제(에녹사파린, 프락시파린, 와파린 등). → [혈전·호흡곤란 응급 기준](../emergency/thrombosis.md)

## 섬망 { #delirium }

섬망은 다른 신체 질환을 경고해 주며 치사율도 높아 **의학적 응급**으로 간주한다.

**증상**: 수면 장애(주로 밤에 불면) · 환시 · 지남력 저하(날짜, 가족·의료진, 장소를 구별 못 함) · 의식 장애, 집중력 저하 · 사고 장애(비논리적 사고, 피해망상, 의심) · 정신운동 장애(과다 각성·초조·과민·산만, 또는 각성 저하·혼동·진정) · 공격적·충동적 행동 · 증상이 좋아졌다 나빠졌다 변동.

**진단**: 다른 질환과 감별하려고 혈액·소변 검사, 뇌 CT·MRI, 뇌척수액, 뇌파 검사 등을 한다.

**대처**:
1. 원인 질환 치료
2. 환경 조절: 환자를 적정 수준으로 자극(은은한 조명, 밤낮 구별되는 창문 있는 방). 친숙한 환경(가족이 간호, 평소 쓰던 물건을 병실에). 오늘 날짜·장소·상황을 알려 주기. 시력·청력 저하 시 안경·보청기. 강한 불빛, 그림자, 소음 같은 불필요한 자극 최소화
3. 약물: 심한 초조·흥분 시 소량의 항정신병 약물. 수액·전해질 균형, 영양·비타민 공급. 섬망 환자는 약물 부작용에 민감하므로 불필요한 약, 특히 진정제·수면제는 중단하는 것이 좋음

## 뇌졸중 { #stroke }

**증상**: 반신 마비 · 반신 감각 장애(몹시 불쾌하게 저리거나 아픔) · 언어 장애(실어증) · 발음 장애 · 운동 실조(걸을 때 한쪽으로 쏠려 넘어짐) · 시야·시력 장애(갑자기 한쪽 눈이 안 보이거나 시야 한 귀퉁이가 어둡게) · 복시 · 연하 장애(삼키지 못하고 사레, 침 흘림) · 치매 · 어지럼증 · 의식 장애(가장 심하면 혼수) · 처음 경험하는 극심한 두통이 갑자기 생기며 의식을 잃음.

**예방**: 갑작스러운 추위 노출 피하기 · 지나친 운동, 과로, 탈수 조심 · 혈압이 몹시 높거나 동맥류가 있는 사람은 대변 볼 때 무리하게 힘주거나 지나치게 흥분하면 뇌출혈·지주막하출혈 위험 · 혈관 상태가 나쁘거나 고령이면 탈수 상태에서 뇌졸중이 유발되기도 하므로 목욕을 너무 오래 하거나 더운 곳에서 탈진할 정도로 일하지 않기.

## 림프부종 { #lymphedema }

**부종**: 세포 사이 조직 공간에 비정상적으로 많은 체액이 있는 것. **림프부종**: 림프계 손상·기능 이상으로 림프액 수송이 떨어져 단백질이 풍부한 간질액이 피부·피하조직에 쌓이는 것.

**징후**: 반대쪽과 차이 나게 부음 · 누르면 자국이 남음 · 수술한 쪽 팔(다리)이 욱신, 당기고 무거운 느낌 · 팽창감, 단단한 느낌 · 피부가 붉고 열감.

**단계**: 1단계 누르면 자국이 남음 → 2단계 피부가 단단해져 눌러도 안 들어가고 올려놓아도 잘 안 빠짐(비가역적) → 3단계 부종이 줄지 않고 반복 감염, 섬유화, 피부·근막 변화.

**검사**: 둘레·부피 측정(줄자, 체적 측정기), 초음파·림프신티그라피, 다주파수 바이오임피던스(인바디), CT, MRI.

**가정에서**: 부종 부위를 **심장보다 높게** 두고 손발 잼잼(펌핑 운동). 초기에 치료 없이 방치하면 섬유화로 딱딱해지므로 **초기 치료가 중요**. 운동·스트레칭으로 근육 펌프 작용을 늘림.

**셀프 마사지**: 피부에 직접, 한 부위 5~10회, 로션·오일 없이, 느리고 천천히. 림프관은 표층에 있으므로 피부가 약간 밀릴 정도(500원 동전이 올라간 느낌)의 가벼운 압력으로 림프절 방향(귀밑, 쇄골, 목, 겨드랑이, 복부, 서혜부, 오금)으로 쓸어올리듯. 림프절 절제를 했으면 다른 림프절로 보낸다. 양쪽 팔 둘레가 2cm 이상 차이 나면 전문 치료 필요.

**주의**: 과한 압력 금지 · 상처 나면 감염 위험 · 뜨거운 찜질·사우나는 림프액 생성을 늘림 · 무거운 물건, 꽉 조이는 옷 피하기 · 부종이 심해지면 항생제가 필요할 수 있음 · **진행 중인 암환자는 림프절 도수 마사지 금지** · 장시간 비행·여행 피하기 · 수술 안 한 팔에서 채혈·주사 · 부항·침·뜸 금지 · 목욕탕·사우나·뜨거운 찜질 금지 · 더운 여름 격한 운동 주의 · 팔이 붓는 경우 담당의와 즉시 상담. 압박스타킹은 하루 종일, 수면 시 다리를 심장보다 높게. (행복방)

## 응급실에 보호자로 갈 때 꿀팁 5 (행복방) { #er-tips }

1. **집에서 쓰던 담요·작은 이불**을 가져간다. 여름 응급실은 에어컨으로 매우 춥고 밝은 조명과 얇은 이불은 심적 안정이 안 된다. 체취가 있는 폭신한 이불이 환자를 안정시킨다.
2. **증상을 구체적으로 기억해 설명**한다. 오늘 몇 시부터 어떤 증상이 시작되어 지금 어떤 상태인지.
3. 구급차 이동 중 환자 옆에서 손을 잡고 침착하게 상황을 말해 준다.
4. 수납 시 **보험 청구 서류**를 함께 발급받는다. 환자는 아무것도 신경 쓰지 않게.
5. 응급환자 수송 시 **버스전용차선**을 이용할 수 있다(깜빡이 필수). 고지서를 받으면 증빙서류를 제출해 과태료를 면제받는다.

**입원으로 이어지는 일이 많으니** 입원 준비물을 캐리어에 미리 싸 두고 응급실에 끌고 간다. → [입원 준비물](before-chemo.md#packing)

### 응급 이송 시 과태료 구제 서류 (행복방 경험)

1. 응급실 내원 기록(내원 시간 표시) 2. 의사 소견서(응급 상황이라는 소견 필수) 3. 차량등록증 4. 면허증 5. 환자와 차량 소유자의 가족관계증명서

거주지 관할 경찰서 민원실에 "응급환자 이송 시 과태료 구제 신청"이라고 하면 접수해 주며, 속도 위반 상황 진술서를 함께 쓴다. 1~2주 심사 후 전화로 결과를 알려 준다.

## 구급차·이송 { #ambulance }

- 응급: **119**. 구급차가 어렵거나 비응급 전원에는 **사설(민간) 구급차**를 이용한다. 행복방 문서에는 전국 시·군별 민간 구급차 업체 목록(2023년 블로그 자료)이 있으나 번호가 바뀔 수 있어 이 사이트에는 싣지 않았습니다. 현재 목록은 **응급의료포털 E-Gen**(https://www.e-gen.or.kr)에서 "민간 이송업체"를 검색하세요.
- **"응급의료정보제공" 앱**을 설치하면 응급 상황에서 모든 대학병원의 잔여 병상과 상황을 볼 수 있다. ("잘하자님" 정보)
- 코로나 등 격리 상황에서는 사설 구급차 이용이 불가능할 수 있다. 담당 병원에 이송을 요청하거나 119에 요청한다.
