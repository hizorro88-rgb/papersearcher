# 항암 시작 전 준비

!!! quote "출처: 행복방"
    "항암 전에 해야 할 일"과 행복방 조언 목록, 입원 준비물을 옮겼습니다.

## 항암 전에 해야 할 일 (행복방)

1. **눈썹 문신**을 한다 (아이라인은 선택). 탈모로 눈썹이 빠지기 전에.
2. **예방접종**을 한다 (폐렴 2종, 대상포진). 아래 참고.
3. **여행** 다녀오기.
4. **날것, 특히 회**처럼 항암 중 못 먹는 것을 꼭 먹어 두기.
5. 항암 전후로 심리적으로 힘들거나 우울감이 느껴지면 **암스트레스클리닉, 정신건강의학과** 진료를 추천.

## 예방접종 { #vaccines }

행복방 문서는 두 곳에서 접종을 다룹니다. 첫째 부분(버니님 경험):

- **독감(5가)**, **폐렴(프리베나13가 먼저 접종 후 2개월 뒤 23가)**, **대상포진(생백신은 항암 2~4주 전에 접종해야 함)**.
- 항암 중 폐렴이 생기면 너무 힘들어지고 회복도 더디며 항암이 중단된다. 면역력이 떨어져 대상포진도 자주 발병한다. 꼭 항암 전에 접종을 완료하고, 못 했다면 항암 중 일정이 생길 때 챙긴다.

둘째 부분(항암 중 접종 가능 여부, 원출처 의료진 블로그 정리):

- 항암 중 **독감 백신과 폐렴구균 백신은 접종을 추천**한다. **생백신인 대상포진 백신은 항암 중 맞으면 안 된다.** (현재는 사백신 대상포진 백신도 있으니 의료진과 상의)
- 독감: 감염을 60~80% 낮추고 중증·합병증을 예방. 매년 10~11월. 백혈구 수치가 호전됐을 때 맞는 것이 좋고, 항암 후 7~10일은 호중구 감소가 예상되어 접종 후 발열이 호중구성 발열과 혼동될 수 있으며 혈소판 감소로 멍·혈종이 생길 수 있다. **항암 스케줄 초기에** 접종하는 것이 좋을 수 있다. 가족도 함께 접종.
- 폐렴구균: 수막염·패혈증 등 침습성 감염을 50~80% 예방. 65세 미만은 고위험군(당뇨, 심장·폐·간 질환, 면역억제제, 악성종양 등)이 접종. 항암 시작 전이면 10주 전, 이미 시작했으면 스케줄 초기에. 독감과 같이 맞아도 된다.

## 동네 2차병원을 미리 "뚫어" 두기 { #local-hospital }

행복방이 "각 목록에서 가장 중요한 것"으로 꼽은 항목: **동네에서 묻지도 따지지도 않는 '혜자스러운' 2차병원·내과를 접수해 두는 것.**

쓰임새 (행복방 경험):
- 구토가 시작됐을 때 주사제로 가라앉히기
- 본원에서 "증상 없이는 처방 못 한다"고 할 때 구토·설사·변비약 미리 처방받기
- 항암 하루 이틀 전 **혈구 확인**, 호중구 촉진제(류코스팀·뉴라스타) 맞기 (지방 환자)
- 아미노산·오마프원 같은 **영양 수액**
- 간수치 높을 때 우루사·고덱스 처방
- 나중에 본원에서 안 해주는 **수혈**을 받을 수 있는 조금 큰 종합병원도 하나

## 약을 1차부터 미리 받아 두기

처방을 잘 해주는 주치의는 "부작용을 먼저 겪고 두려움을 가질 필요가 없다"며 1차 때 약을 다 처방해 준다. 그렇지 않은 주치의를 만나면 온몸으로 부작용을 견뎌야 한다. **구토약, 설사약, 변비약, 구내염약, 진통제**를 1차 전에 챙긴다. (행복방) → [항암 부작용별 대처](chemo-side-effects.md)

## 입원 준비물 체크리스트 (행복방) { #packing }

입원 준비물을 **여행용 캐리어에 미리** 챙겨 두고 응급실 갈 때 환자와 함께 끌고 간다. 응급실은 입원으로 이어지는 일이 많고, 급하게 싸면 빼먹는 것이 많다.

| 물품 | 물품 |
|---|---|
| ☐ 보호자 이불·베개 | ☐ 슬리퍼(환자용, 보호자용) |
| ☐ 전기온열패드 | ☐ 물통 |
| ☐ 찜질기 | ☐ 빨대컵 |
| ☐ 충전기 | ☐ 일회용컵 한 줄 |
| ☐ 멀티탭 3m 정도 | ☐ 일회용 숟가락 |
| ☐ 영상 틀어드릴 기기(태블릿) | ☐ 일회용 젓가락, 젓가락 |
| ☐ 속옷 | ☐ 빨대 |
| ☐ 수건 2개(한 개는 푹 적셔서 걸어두기) | ☐ 과도(제한하는 곳 있음. 접이식 칼이 편함) |
| ☐ 작은 쟁반 | ☐ 일회용 페이스타올 |
| ☐ 세면도구 | ☐ 가제수건(입술 수분 공급용) |
| ☐ 가위 | ☐ 곽티슈 |
| ☐ 작은 대야, 바가지 | ☐ 화장실 티슈 |
| ☐ 환자용 조끼나 숄 | ☐ 물티슈 |
| ☐ 보호자용 조끼 | ☐ 위생팩 |
| ☐ 500ml 생수(삼다수를 많이 준비) | ☐ 휴대용 가습기(가을용/여름용) |

## 상비약 (행복방)

- 체했을 때: 편의점 **닥터베아제(주황색)**
- 감기 증상: 콜대원(파랑: 인후·몸살). 기침·가래에는 대체로 고푸시럽에스
- 코로나 검사 키트
