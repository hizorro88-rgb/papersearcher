# 임상시험 참여 방법 안내

임상시험은 아직 승인되지 않은 신약이나 새로운 조합을 시험하는 연구입니다. 표준 치료가 제한적인 췌장암에서는 임상시험이 중요한 치료 선택지가 될 수 있습니다. 다만 **참여가 곧 효과를 보장하지는 않으며**, 이익과 위험을 담당 의료진과 함께 따져야 합니다.

## 1. 어디서 찾나

| 경로 | 설명 |
|---|---|
| [이 사이트의 임상시험 목록](../../_generated/trials/index.md) | ClinicalTrials.gov에 등록된 췌장암 시험을 매일 갱신. **국내 실시기관이 있는 시험**을 따로 모아 둠 |
| ClinicalTrials.gov | 전 세계 임상시험 등록소 (영어) https://clinicaltrials.gov |
| CRIS (한국 임상연구정보서비스) | 질병관리청 운영, 국내 등록 임상연구 https://cris.nih.go.kr |
| 식약처 임상시험 정보 | 승인된 임상시험 계획 목록 https://nedrug.mfds.go.kr |
| 각 병원 임상시험센터 | 병원별로 진행 중인 시험을 안내 ([병원 연락처](../emergency/hospital-contacts.md)) |
| 담당 주치의 | 가장 확실한 경로. 내 상태에 맞는 시험을 알고 있거나 다른 병원에 의뢰해 줄 수 있음 |

## 2. 참여 조건 읽는 법

각 시험에는 **선정 기준(inclusion criteria)**과 **제외 기준(exclusion criteria)**이 있습니다. 이 사이트의 시험 페이지에서 AI가 핵심만 한국어로 정리해 두었지만, 최종 판단은 원문과 의료진 확인이 필요합니다. 자주 나오는 조건:

- **병기·상태**: 절제 가능 / 경계성 절제 가능 / 국소 진행 / 전이성
- **이전 치료**: 1차 치료 전(치료 경험 없음)인지, 1차 치료 후 진행(2차 이상)인지
- **유전자·바이오마커**: KRAS G12C/G12D, BRCA1/2, MSI-H, HER2 등 → **종양 유전자 검사(NGS)** 결과가 필요한 경우가 많음
- **전신 상태**: ECOG 수행 능력 0~1 (일상생활이 가능한 정도)
- **장기 기능**: 간·신장·골수 수치 기준 (황달이 있으면 빌리루빈 수치로 제외될 수 있음)
- **제외 사유**: 뇌 전이, 다른 암 병력, 특정 약 복용, 조절되지 않는 감염 등

## 3. 신청 절차

1. **후보 시험 고르기** — 이 사이트의 "국내에서 모집 중" 목록에서 내 상태에 맞을 만한 시험을 2~3개 고릅니다.
2. **주치의와 상담** — 시험 번호(NCT…)를 보여 주고 참여 가능성을 묻습니다. 다른 병원에서 진행 중이면 진료 의뢰서를 써 줄 수 있습니다.
3. **임상시험센터 문의** — 해당 병원 임상시험센터 또는 시험 페이지의 연락처로 "참여 가능 여부를 문의"합니다. 진단명, 병기, 이전 치료, 유전자 검사 결과를 준비하세요.
4. **스크리닝 검사** — 혈액검사, 영상, 조직검사 등으로 선정 기준을 확인합니다 (보통 1~3주).
5. **동의서** — 연구 목적, 절차, 위험, 비용, 언제든 중단할 권리를 설명받고 서명합니다. 충분히 질문하세요.
6. **등록·치료 시작**

## 4. 꼭 물어볼 질문

- 이 시험은 몇 상(phase)이며, 지금까지 어떤 결과가 있나요?
- 무작위 배정이라면, 대조군은 어떤 치료를 받나요? (위약만 받는 경우는 드물지만 확인)
- 참여하면 받을 수 없게 되는 다른 치료가 있나요?
- 비용은 누가 부담하나요? (시험약은 보통 무료, 검사·교통비는 다를 수 있음)
- 중간에 그만둘 수 있나요? 그만두면 어떤 치료를 받나요?
- 부작용이 생기면 누구에게 연락하나요?

## 5. 비용과 권리

- 시험 약물과 시험 목적의 검사는 일반적으로 의뢰자(제약사·기관)가 부담합니다.
- 참여자는 언제든 이유 없이 참여를 철회할 수 있으며, 철회해도 표준 진료에 불이익이 없어야 합니다.
- 피해가 발생하면 보상 규정이 있습니다 (동의서에 명시).
