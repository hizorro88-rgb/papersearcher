# 췌장암 정보 위키

췌장암 환자와 보호자가 **지금 필요한 것을 빨리 찾도록** 만든 공개 위키입니다. 응급 대처, 치료 설명, 임상시험, 환우 커뮤니티의 투병 경험을 한곳에 모으고, 최신 논문·소식은 매일 자동으로 수집해 한국어로 요약합니다.

!!! danger "지금 문제가 생겼나요?"
    **[증상·상황으로 찾기](guides/happybang/find-by-symptom.md)** — 토함 · 열 · 설사/변비 · 손발 저림 · 입안 헒 · 통증 · 황달 · 어지러움 · 붓기 · 못 먹음 · 검은 변 … 일상 말로 찾습니다.
    **[응급 가이드](guides/emergency/index.md)** — 바로 응급실에 가야 하는 기준. 응급 시 **119**.
